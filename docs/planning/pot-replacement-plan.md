## 1 目标、状态与执行原则

用户于 2026-10-11 先要求设计和规划，随后授权执行本计划。0.5.0 已接通五阶段的首版能力，schema 为 7；实际检查和未覆盖项见 [Pot 替代验证](../testing/pot-replacement-results.md)。本文件保留开发顺序，不能把代码接通等同于全部桌面或兼容验收通过。

已有取词、OCR、本地解释、Windows 英语语音、词库合并、托盘与三组快捷键作为基础。先完成本地查词闭环，再加入自动采集和监听，最后扩展服务与插件。阶段只代表依赖顺序，不预填发布日期、开发工时或功能已完成状态。

每阶段直接在当前分支实现，按变更范围执行最小正常检查并提交；不逐功能打包。新增大功能按既有规则递增次版本、修复递增补丁版本，主版本继续由用户决定。打包和发行验收由用户需要发布时另行发起。

## 3 各阶段工作包

### 3.1 M-09：查询与收录解耦

1. 固化 CMD-38 至 CMD-41 的会话／查询类型、数据版本与取消语义。
2. 增加查询缓存迁移，保留旧 explanations，查询不产生词条或学习变更。
3. 实现小窗布局和输入操作；服务详情默认折叠，不把主窗口完整导航搬入小窗。
4. 复用本地模型和声音；进入收录时复用 collection_* 及已有草稿队列。
5. 最小检查后记录窗口、实际翻译和收录结果；语音效果需要实际听辨，不只检查文件存在。

### 3.2 M-10：采集自动查询

1. 采集完成前不改变原应用焦点；OCR 截图前不遮挡桌面。
2. 将捕获的目标、完整语境和来源元数据交给 QuerySession。
3. 自动入口只调用已允许自动查询的服务，默认本机模型；缓存结果先展示。
4. 接通托盘与快捷键，保留自定义、占用提示、已掌握跳过和明确查看路径。
5. 查询和错误留在小窗，正常操作不增加后台任务噪声。

### 3.3 M-11：监听与用户控制

1. 接入 Windows 原生剪贴板变化通知，只读取新的纯文本。
2. 实现显式开关、启动关闭、合并和去重；处理本程序复制译文的序号。
3. 自动监听只保留最新待发输入，按会话版本展示结果。
4. 关闭监听取消其查询，托盘与小窗显示同一真实状态。
5. 设置监听结果是否持久化，保持缓存与词库／同步边界清晰。

### 3.4 M-12：内置服务先行

1. 把 Qwen、既有词典／翻译查询整理为能力明确的适配器。
2. 增加服务配置、发送字段、凭据引用、自动开关和独立并发。
3. 实现多个结果分开显示、先完成先展示及用户选择某一结果收录。
4. 服务标识、配置指纹进入缓存，换服务不误标旧来源。
5. 正常检查使用已配置服务或合成接口，不迁移 Pot 凭据或申请新账号。

### 3.5 M-13：小规模插件规范

1. 确定首版 manifest、HTTP 模板、响应映射及支持的 capability。
2. 交付一个合成翻译插件示例，先验证协议与生命周期，再接真实服务。
3. 实现安装、能力校验、配置、启用／禁用及卸载，凭据由宿主管理。
4. 记录包来源、许可、主程序版本和协议版本；用户资料不进入插件包。
5. 如需迁移具体 Pot 插件，先形成独立兼容评估；OCR／语音插件和完整 .potext 兼容后续排期。

## 4 依赖与待决策项

| 事项 | 决策点 | 处理阶段 |
| --- | --- | --- |
| 小窗尺寸、靠近光标与固定行为 | 按实际可用工作区确认默认布局，避免复用过大的主窗口 | M-09 |
| 查询缓存迁移与服务身份 | 保留旧本地解释；新缓存必须区分模式、语言与服务配置 | M-09、M-12 |
| 交互优先与后台模型并发 | 不终止在途批次，不超出用户并发值；优先调度下一空闲许可 | M-09 |
| 剪贴板合并间隔 | 初始 300 ms；是否需要用户设置范围按真实交互核对，不先跑负载测试 | M-11 |
| 首批外部服务 | 优先现有接入；新增服务在实施前核对文档、许可与发送范围 | M-12 |
| 插件包与版本兼容 | 声明式配置先行，Pot 原包兼容另行评估 | M-13 |

本地模型不可用不阻塞小窗输入、已有结果或原词库。Pot 占用相同热键时先由用户退出 Pot 再验证新应用；不通过自动终止其他应用取得快捷键。

## 5 验证、文档与完成条件

各阶段只执行直接确认请求功能的最小正常路径、必要类型／编译检查，完成后交付。故障注入、竞态、兼容矩阵、容量、吞吐、压力和长期监听等扩展检查须提前说明目的与预计成本，并获得用户明确授权；设计中的验收规则不等于这些检查已经获准执行。

实施时同步更新 PRD、设计、命令／数据结构和真实验证记录。记录应包含需求／场景编号、版本与提交、输入、实际结果和未覆盖边界。未实施阶段保留“待开发”，局部成功不代表 Pot 所有功能均兼容。

文档阶段已完成需求、设计与阶段追溯。0.5.0 首版已完成最小正常流程、必要编译／类型检查和用户桌面确认，实际范围见增量记录；公开材料仅包含自编夹具和插件示例，没有用户素材、凭据或词库，不生成发行包。
