## 1 行为与范围

本地设置增加独立的“开机启动（登录 Windows 后）”开关。未登记时默认关闭，进入设置读取当前用户登记；切换立即写入／移除并回读结果，不依赖页面的“保存设置”。登录启动正常显示主窗口，关闭到托盘独立选择；完全退出不取消下次登录启动，关闭开关也不退出当前程序。

实现使用现有 windows crate 的 Registry API，HKCU Run 中仅操作本产品值，不新增服务、数据库字段、迁移或同步内容。登记包括当前 exe 和带引号的 `--data-dir` 绝对目录；资料目录解析先识别该参数，再沿用环境变量及默认值。不会随词库复制到其他设备，不自动给用户开启，不改写个人词库、例句、原声、学习历史或凭据。接口与系统策略边界见[接口设计](../design/interfaces.md#9-windows-开机启动0831)。

## 3 交付和保留边界

本轮没有重启、注销登录、操作设置页实际开关、重编译并启动桌面 exe、打包或安装，不能把注册表正常写读当作完整登录现场验收。外部任务管理器和系统策略仍可影响最终启动，本程序回读的是自己的登记值，不宣称控制全部系统审批状态。

当前原窗口显示、单实例、后台任务恢复及关闭／托盘流程保持。源码修复不会自动替换用户正在运行的安装版；正式使用应在稳定、可独立启动的程序位置开启。移动程序或资料目录后需关闭再开启，以更新登记路径。未执行覆盖安装／卸载验收，也未改变发行脚本。

## 4 复选框布局修复（0.8.34）

用户截图显示复选框居中、文字落到下一行。原因是 StartupSettings 使用 `checkbox` 类，但该类没有通用布局规则，实际命中全局 `label { display:grid }`。改用项目已有 `check-label`，复选框尺寸与同行对齐随之恢复；没有修改启动登记逻辑。

最小正常验证使用生产 StartupSettings 组件与完整生产 CSS，在真实浏览器的 960×640 页面渲染设置卡片及相邻关闭下拉选项。仅以合成 IPC 返回 `autostart_get=false`，没有调用 autostart_set 或操作实际启动项。实测标签为 flex、复选框 16×16、文字间隔 9px、中心纵向差约 0.32px；相邻下拉选项标签保持 grid，页面无横向溢出。已查看截图，视觉位置正常。

脚本、结果和截图保留于 `output/playwright/startup-layout-0.8.34`。版本及差异检查通过；未扩大到缩放矩阵、重新验证 Windows 登录、编译桌面程序或生成安装包。
