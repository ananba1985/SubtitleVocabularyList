## 3 用户安装与操作验证

1. 从托盘退出旧版，运行安装器，继续选择原安装目录 `D:\SubtitleVocabularyList`，沿用其 Data。
2. 使用软件全屏按钮进入全屏后直接按空格，确认暂停／恢复；移动鼠标后可从原生控制条齿轮进入播放器设置。
3. 切换到其他视频，确认上方剧集信息与当前播放一致；未导入的视频应在后台准备字幕与资料，完成后对应到该视频。
4. 在窗口模式打开同目录有同剧其他集的视频，检查提示数量和展开后的文件名。可选择“仅导入当前集”，或确认“导入其余 N 集”，再到后台任务页查看批量进度；当前视频应继续播放。

本轮未运行安装器或客户端，未操作系统鼠标键盘或正式资料库。实际安装、声音、原生窗口和真实剧集下后台处理表现由用户验证，不以打包成功替代功能实测。
