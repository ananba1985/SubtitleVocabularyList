## 5 TC-54：一个分层会话、作答与重开继续流程

M-16 使用 M-15 的 schema 9，不新增迁移、不重跑未变化的 TC-53。新增 assessment.rs 和 assessment_sampling.rs，并注册 CMD-50 至 CMD-55、CMD-57 及待继续会话分页命令；尚未接入真实桌面入口。

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --lib assessment_tests::tc54_stratified_offline_session_and_resume -- --nocapture
```

合成题库有 6 个目标，分别位于原排名 1–1000／1001–2000 两个频段，每个目标有事先核对的辨识、填空和听音题；这些目标均标为全局已掌握，另有已有个人词条及人工释义、例句和复习状态。预览 Top 2000／6 题，验证每个频段×题型配额为 1、可用目标为 3；开始后确认实际为 6 个唯一词元，每频段 3 题。

保存当前输入草稿，暂停、关闭数据库并重开，再继续原题；完成六个位置的普通作答及不知道。听音位置发送关联播放 ID 的开始／结束回执，填空合理变体进入待确认，追加一次人工判分修正；正常请求使用同一操作标识读取已提交回执，检查每位置仍只有一份作答。

结果：**1 passed，0 failed**。

- 已掌握标记不筛除摸底目标；题库、来源、seed、题序和选项固定保存，重开后 id／完整快照逐字保持，草稿恢复。
- 公开题面没有未作答答案字段；选项 ID 不沿用含答案含义的原 ID。听音题公开投影不包含英文目标，只有播放与中文选项。
- 六个位置完成，提示与不确定事实保存；修正追加为一条记录，原 answer_json 未覆盖，hinted 不因修正清除。
- 原词条数、人工释义、全部原复习状态、原复习作答数及 6 个已掌握标记保持不变。作答、恢复及判分没有模型调用。

听音回执在此仅为合成核心事件，**不是实际播放器或真人听感证据**，TC-55 仍需在真实桌面验证。M-16 最终代码的桌面 `cargo check --features desktop`、`pnpm version:check` 通过；应用保持同一 0.8.0 大功能开发版本，不为阶段提交重复递增或打包。未运行扩展回归或故障注入。
