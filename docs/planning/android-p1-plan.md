## 1 维护边界

沿用 Android 独立运行架构。直接复用桌面的 PracticeView／usePracticeSession、EpisodesView／useEpisodePreview、AssessmentView 与报告／历史／确认收录页面、OnlineSubtitlePanel，以及原 Rust Store、查询会话、题库、抽样、判分和 assessment-1 同步。Kotlin 只负责系统文件／目录授权、Media3 音频与字幕渲染、容器章节和平台控制；没有第二套业务数据库或判分算法。

课程正文、输入草稿、观看偏好和目录授权留在本机；个人收录仍走原统一确认与合并。高频测试保持独立历史同步，不改变计划复习。手机不依赖电脑开机、局域网或桌面模型；可选查询和题库准备使用本机已配置服务并由用户明确触发。

## 3 平台支持范围

- 阅读使用现有共享文件解析器，手机系统选择单文件后读取；文件入口限定 32 MiB。课程原声和生成语音通过原本机音频接口播放，播放区间和速度由平台播放器执行，练习状态仍在共享会话。
- 预习使用手机已授权且已有文本索引的资料；目录索引只读所选目录直接包含的视频，最多 100 个，不递归、不启动整季 AI，确认前不追加到播放列表。
- 原声与自动语音标签、真实播放完成记录分别保留。同步到手机的旧系统语音可以用手机本地英语声音重建缓存，不改写冻结试题与原成绩。
- 主字幕继续交给 Media3；第二行显示同一 Store 对齐后的中文字幕。可调字号与背景；章节读取 MP4 的 chpl 和 Matroska Chapters，未识别的章节明确显示无可读取项，不推断无根据的章节。
- A/B 循环在本机播放器执行，设置 A 后才允许设置后方 B；切换视频使用各文件自己的偏好。
- 在线字幕继续 SubDL 单一明确授权服务，不加入自动跨服务检索；查询对比仅对明确勾选操作发送给已启用内置服务，不支持桌面插件执行。

## 4 当前交付

AND-M-10 至 14 已在 0.26.0 接入并完成所需正常本机检查。AND-M-12 同账号真实服务器交换收到完整报告、题目／作答及收录关联；AND-M-14 实际两个免费服务并列返回并明确采用。详见 [P1 结果](../testing/android-p1-results.md)。Windows 开发入口、唯一 IPC／TypeScript 及 Android Rust／Kotlin 构建通过，手机调试升级保留资料。

SubDL 基础 key 免费，官方当前说明为每日 2,000 API 请求；普通下载有免费额度，AI 与更高配额另有付费方案。按用户明确决定，只保留免费基础检索／普通下载的可选设置，不引入付费 AI／订阅，也不要求用户提供 key 才交付本轮开发。[官方 API 说明](https://subdl.com/api-doc)
