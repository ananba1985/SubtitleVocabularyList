## 1 交付文件与适用环境

本文原有安装和使用记录对应 0.1 候选包。0.6.1 的资料目录规则见 2.1；[新版安装测试包](0.6.1-release-notes.md)已生成，实际安装与使用仍待用户验证，不能用现存 0.1 包验证新路径。

交付目录包含 Windows x64 安装器 `SubtitleVocabularyList_0.1.0_x64-setup.exe`、`SubtitleVocabularyList_0.1.0_source-materials.zip` 和 `SHA256SUMS.txt`。安装前可用 `Get-FileHash` 核对摘要。最终包以随包清单为准；安装候选包和开发程序的结果不能自动表示发布验收完成。

当前实际安装验证环境为 Windows 11 x64、当前用户安装和现有 WebView2。包内准备 WebView2 离线安装程序、FFmpeg/ffprobe、英语 OCR 资源、Whisper CLI 与英语模型。最终用户运行无需安装 Node.js、Rust、Visual Studio、Pot 或开发媒体工具。

本地 Qwen 服务和 Windows 英语声音是用户系统资源。解释使用已配置的 `http://127.0.0.1:8096`，模型默认标识为 `Qwen3.5-9B`；该服务不随单词本安装。服务不可用时仍可手动填写释义、浏览、播放、基础测验和收录。系统语音需要 Windows 已安装的英语声音；没有声音时应在系统设置准备后再使用。

## 2 安装、数据与重装

运行安装器，按当前用户安装流程选择位置。安装目录保存程序和 tools；个人词库默认位于 `%APPDATA%\com.subtitlevocabularylist.desktop`。可在“本地设置”查看当前数据目录与资源状态。截图、后台任务文件和已经收录的独立原声保存在数据目录中；它们不依赖源剧集一直存在。

正式使用前备份时应从托盘“退出”完全停止程序，再复制整个数据目录。不要只复制 SQLite 主文件而遗漏事务文件或媒体。重装不能代替备份；应保留词库和媒体，并让应用通过数据库迁移打开旧词库。比当前版本更新的词库会被拒绝打开，避免旧程序改写新结构。

独立测试可在 PowerShell 设置 `SVL_DATA_DIR` 后启动指定安装目录的程序。这个环境变量用于隔离测试和自定义资料位置；已有程序不会继承后来设置的变量，应先完全退出。安装验证记录没有改动正式词库。

### 2.1 0.6.1 起的资料目录规则

用户在安装器选择程序位置；新代码使用该位置下的 Data 保存业务资料、cache/webview 和 cache/temp，不再通过 AppData 选取独立资料库。本机用户选择 D:\SubtitleVocabularyList，本地 debug exe 和调试入口也默认使用 D:\SubtitleVocabularyList\Data。正式打包仍由用户手动执行，程序关闭后再切换运行方式。已有资料已迁移及本地实际结果见[目录说明](../development/data-directory.md)；本段不修改前述历史 0.1 安装行为。

### 2.2 0.7.3 起的随包基础词库

本节对应当前源码流程，**本轮未生成安装器或 exe**，旧安装包不因此获得新资源。

后续在开发机执行根目录 `生成安装包.ps1` 时，会先用 Python 3 从固定提交及 SHA-256 的原始资料生成 Google 高频词库和 ECDICT，再执行原有构建。原始文件在项目 `.tools/release-cache/dictionaries` 缓存，不读取开发机的个人数据库。`-SkipToolBuild` 只跳过媒体工具重建，不跳过底库准备；缺失／准备失败不会生成缺词库的包。最终用户不需要 Python，安装和启动时无需为词库联网下载。

安装器按所选路径自动写入以下文件，例如选择 `D:\SubtitleVocabularyList`：

```text
D:\SubtitleVocabularyList\Data\dictionaries\
  base.sqlite3             Google 高频词库
  ecdict.sqlite3           ECDICT 后备词库
  manifest.json            来源提交、摘要与词条统计
  notices\                 上游 README 和 ECDICT LICENSE
```

升级时先退出正在使用同一资料目录的客户端，选择同一安装位置，底库由安装器更新；原有 `Data\vocabulary.sqlite3`、词条例句、已保存解释、学习记录、媒体和同步资料不属于底库安装资源，不被覆盖。不通过新安装位置自动迁移旧资料。独立运行目录也包含上述底库，其资源复制仅更新列明文件，不整体替换 Data。

资源准备、首次落盘及保留合成个人库的更新检查见[验证记录](../testing/dictionary-packaging-results.md)。真正 NSIS 构建、覆盖安装和卸载验收留到用户需要生成版本包时执行，不以本地复制结果冒充实装。

## 3 基本使用流程

1. 在“观看前预习”导入视频或文件夹，确认音轨、字幕或本地转写选项。默认按单词和短语浏览，展开出现语境，修正识别文字及时间后决定是否收录。
2. 收录窗口中确认词条、释义和例句；选择保存原声。重复收录可以合并到已有词条，保留新的例句、语境、原声和主动收录记录。
3. “我的单词本”用于浏览与播放；阅读和播放不会自动计为测验通过。
4. “主动回忆测验”分别安排词义和听力，听力题先播放再作答；可以使用提示、确认或修正判分。易忘词进入专项练习。
5. 全局划词默认 `Ctrl+Alt+Shift+W`，截图 OCR 默认 `Ctrl+Alt+Shift+S`。可在本地设置修改。采集结果需要确认，不会直接写入词库；连续采集按队列处理。
6. 默认离线模式。需要在线词典、翻译或同步时先关闭离线模式，再手动触发。在线查询界面显示本次发送文字与提供方；本地模型解释仍通过回环服务处理。
7. 在“站点同步”发起设备连接，在英语练习站点登录并核对设备名和连接码后批准。同步范围包括词条、例句、原声、收录和学习记录；两端冲突保留待选择版本。

关闭主窗口后应用留在托盘，全局采集仍可使用；需要彻底停止时选择托盘“退出”。

## 4 当前验收边界

笔记本上已经通过安装、资源核对、词条保存与原声/系统语音播放、双维度作答、同版本重装、真实 schema 4→5 迁移和新包源码匹配校验。完整 3000 条作答与原声已通过站点分段同步，网页历史每页显示 20 条。台式机已补测 WPF 划词、空选区、队列、截图和剧集候选生成；界面工具在 Edge 无法确认 URL 后终止，剩余部分未被写成通过。

最新候选包含文件夹与显式文件的路径去重修正，已通过静默实装、程序字节与六项资源核对。本轮没有打开界面，前轮播放与同步证据继续保留其实际版本边界。

指定程序/工具出站限制下的冷启动和核心链路、真人听辨、台式机重装与保存，以及实装性能样本已补测。最终交付及明确支持矩阵见[0.1 候选发布说明](0.1.0-release-notes.md)，未测系统、阅读器和物理多屏不承诺兼容。安装技术结果不代表用户已完成正式学习体验验收。

## 0.16.0 起的文件打开入口（0.16.3 已打包，未执行安装）

用户明确生成并安装新版后，可从视频右键“打开方式”选择 SubtitleVocabularyList。安装器通过 nsis-open-with.nsh 登记本程序的可选入口，覆盖 MKV／MP4／AVI／MOV／WEBM／M4V／TS／MTS／M2TS／WMV／FLV；不写扩展名默认程序或用户 UserChoice。升级更新自己的打开命令和支持类型，卸载仅清理自己的登记。

本地开发版可用 `subtitle-vocabulary-list.exe --data-dir <隔离绝对目录> <视频绝对路径>` 验证参数接收；单实例再次启动将文件交给已有窗口。资料目录仍由原有规则决定，视频参数不作为资料目录。不使用此说明自动构建或安装新包；本轮没有改写本机文件关联。

2026-10-22 按用户请求使用根目录脚本生成 0.16.3 本机试用安装包，包含固定 libmpv 和双底库，打包退出 0，资源／产物摘要核对通过。实际安装和真实剧集试用由用户执行，交付文件、源码身份及材料边界见 [0.16.3 交付记录](0.16.3-release-notes.md)。
