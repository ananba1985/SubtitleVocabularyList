本计划定义 0.1 的验证层次、环境、场景和验收证据。当前仓库尚无应用实现，因此这里的预期结果和场景状态不能作为通过报告。文档本身的格式检查也不能代替功能测试。

## 1 验证层次

| 层次 | 验证对象 | 适用方法 |
| --- | --- | --- |
| 核心规则 | 内容匹配、重试、追加、判分修正、复习维度 | 小规模自动化测试，使用确定输入与数据库结果 |
| 本地集成 | 数据库与媒体提交、模型、转写、OCR、语音 | 真实工具或资源测试，并覆盖失败注入与取消 |
| 桌面流程 | 全局触发、焦点、选区、多屏、预习与测验交互 | 在声明支持的 Windows 环境中操作并检查实际输出 |
| 站点集成 | 认证、字段映射、双向交换、回执与冲突 | 契约测试后使用真实站点账号验证完整流程 |
| 整体验收 | 离线使用、重启保存、资源与异常隔离 | 按 PRD 场景串联执行，核对音频和数据实际可用 |

不为低影响界面文字或简单转发函数编写只重复实现的测试。优先验证可能造成错误收录、数据丢失、误判掌握和同步覆盖的行为。

## 2 环境与测试资料

| 维度 | 需要记录或准备 |
| --- | --- |
| 应用 | 提交标识、构建版本、安装方式与架构配置 |
| 系统 | Windows 版本、CPU、内存、显示器、各屏缩放与坐标布局 |
| 本地资源 | OCR 与转写引擎、模型版本、英语语音、媒体工具和运行时 |
| 网络 | 外网可用、外网断开但本机回环可用、本地模型停止、站点认证失效 |
| 素材 | 有文本字幕、无文本字幕、图片字幕、多音轨、坏文件、时间重叠及缺失片段 |
| 业务数据 | 单词、短语、整句、同词多含义、多来源例句、已掌握与易忘词记录 |
| 站点 | 实际地址、账号范围、接口版本和已确认同步字段；凭据不进入仓库 |

公开测试资料使用自行编写的文本、合成或自录的短音频及可公开的小视频。用户的真实剧集用于本机验证时，记录素材标识与必要结果，不提交剧集或个人词库。

支持矩阵在原型后确定。候选环境未测时标记未验证，不能写成已兼容。无字幕和 OCR 的离线测试应使用新的输入，避免只证明缓存结果可读。

## 3 功能与失败场景

下表所有场景的执行状态均为**未执行**。步骤描述给出最小动作，执行时补充具体素材、配置与实际结果。

| 场景编号 | 需求 | 前置条件与动作 | 预期结果 |
| --- | --- | --- | --- |
| TC-01 | FR-01 | 导入有可用文本字幕和音轨的单个素材 | 得到可浏览的对白与时间位置，预览音频对应 |
| TC-02 | FR-01、NFR-03 | 文件夹包含可用与损坏素材，启动导入 | 各文件状态独立，已完成结果可用，失败可见 |
| TC-03 | FR-01、NFR-01 | 准备本地识别资源，断外网后导入新的无字幕素材 | 生成可纠正的文字与时间位置，无外网依赖 |
| TC-04 | FR-01 | 导入图片字幕、空字幕或无法读取字幕的素材 | 如实识别字幕能力，进入支持的本地路径或报告失败 |
| TC-05 | FR-02 | 同一词在多个对白出现，另有短语候选 | 默认按词或短语展示，重复位置可展开且没有丢失 |
| TC-06 | FR-02、FR-10 | 已收录未掌握词再出现；标记某语境熟悉 | 仍可判断与收录，熟悉不变成全局测验掌握 |
| TC-07 | FR-03 | 在支持应用中选词并触发全局取词 | 获得原应用当前选区，弹窗焦点不使内容错取 |
| TC-08 | FR-03 | 先成功取词，再空选、取消或使取词失败 | 本次不收录旧选区或旧剪贴板内容 |
| TC-09 | FR-04 | 在单屏、多屏与不同缩放下选择已知文字区域 | 裁剪范围与选区一致，识别结果可编辑 |
| TC-10 | FR-04、NFR-03 | OCR 成功后再触发裁剪失败、识别失败和取消 | 无旧截图或旧识别结果冒充本次成功 |
| TC-11 | FR-05 | 分别确认单词、短语和整句，有与无自动来源各一例 | 类型与内容可保存，缺失来源如实显示 |
| TC-12 | FR-05、NFR-02 | 修改自动释义和原文后保存，重启应用 | 用户修订仍保留，未被后续自动建议覆盖 |
| TC-13 | FR-06 | 同一词从新来源明确再次收录 | 新例句与音频追加，旧内容和学习历史保留 |
| TC-14 | FR-06、NFR-02 | 双击确认，并模拟提交成功后响应丢失再重试 | 同一操作只计一次，返回同一提交结果 |
| TC-15 | FR-06 | 对同一来源稍后进行新的明确收录 | 例句与文件不重复，新增主动收录记录 |
| TC-16 | FR-06 | 导入多个出现位置，再重复解析及同步重放 | 来源出现与主动收录次数不同，重试不虚增 |
| TC-17 | FR-07 | 收录并保存对白后移动或删除原素材，再重启 | 已保存原声仍可播放，例句对应不变 |
| TC-18 | FR-07、NFR-02 | 在音频截取、正式文件保存或数据库提交阶段注入失败 | 不产生虚假的可播放引用，草稿与重试路径可用 |
| TC-19 | FR-07、NFR-01 | 无原声，准备 Windows 英语语音后断外网朗读 | 实际能听到朗读，标识为系统语音，停止有效 |
| TC-20 | FR-08、NFR-01 | 外网断开、本地模型可用，解释新的句子 | 得到可修订的语境释义，未发往外部服务 |
| TC-21 | FR-08、FR-10、FR-11、NFR-04 | 停止本地模型后收录原文、浏览和执行基础复习 | 已有内容可用，人工确认路径有效，模型失败可见 |
| TC-22 | FR-08、NFR-05 | 观察联网请求，分别不触发与明确触发在线查询 | 仅在已授权条件发送约定字段；查询失败保留输入 |
| TC-23 | FR-09、FR-10 | 展开释义和例句、播放多次，自由浏览 | 正常浏览与播放，不增加测验正确记录或延长间隔 |
| TC-24 | FR-10 | 从相同学习状态分别提交无提示正确、有提示正确和错误 | 记录三种结果，并按已确定策略产生不同安排 |
| TC-25 | FR-10 | 同一词的词义回答正确，听力回答错误 | 两个维度分别记录，听力困难不被词义结果覆盖 |
| TC-26 | FR-10 | 提交符合语境的同义回答和有歧义回答 | 同义可接受；歧义进入确认，答案显示遵循作答流程 |
| TC-27 | FR-10、NFR-02 | 修正较早一次判分，后面已存在新测验，再重试修正 | 历史保留，相关单元重算一次，其他单元不改变 |
| TC-28 | FR-11 | 使用已确定专项配置，测试阈值前后及退出条件 | 专项原因与维度正确，浏览解释不直接触发退出 |
| TC-29 | FR-06、FR-11 | 已掌握词重新主动收录 | 复习优先状态提高，旧测验与原声保留 |
| TC-30 | FR-10 | 听力题音频不可用，中途退出或取消未提交题目 | 资料错误不计为学习错误，退出不计为通过 |
| TC-31 | FR-12 | 真实站点认证后，本地与在线分别新增再同步 | 两个方向均完成，字段符合已确认范围 |
| TC-32 | FR-12、FR-06 | 首次拉取旧站点词条，多次推拉同一内容 | 映射稳定，词条例句不重复，主动收录计数不虚增 |
| TC-33 | FR-12、NFR-02 | 模拟回执丢失、部分失败及拉取应用中断后重试 | 已处理变更不重复，未应用内容不被游标跳过 |
| TC-34 | FR-12 | 两端修改同一内容后同步并处理冲突 | 保留两端版本，无静默覆盖；处理后结果可追溯 |
| TC-35 | FR-12、NFR-04 | 同步时断网、认证失效或站点异常 | 本地修改保留，本地浏览播放与复习仍可用 |
| TC-36 | FR-12 | 仅在确认媒体或学习记录同步后执行相关交换 | 按批准范围正确传输、去重和关联；未纳入时说明范围依据 |
| TC-37 | NFR-01、NFR-05 | 本地资源齐全，无外网冷启动并串联核心流程 | 导入、OCR、收录、播放和基础复习可用，无隐式资源下载 |
| TC-38 | NFR-02 | 在文件完成但数据库未提交等边界中断应用并恢复 | 无已确认数据丢失、错误引用或重复计数，未引用文件可处理 |
| TC-39 | NFR-03 | 导入进行中浏览词库并取消；另测取消与提交竞态 | 主要操作可用，取消状态真实，已提交内容保留 |
| TC-40 | NFR-03 | 在明确硬件与素材下运行导入、OCR及模型请求 | 记录处理耗时、峰值资源和界面响应，按后续目标评价 |
| TC-41 | NFR-04、NFR-05 | 分别制造解释、查询和同步失败，检查发送范围 | 各失败独立呈现，不扩大外发资料，不破坏已有学习内容 |

TC-36 是同步边界确认后才适用的场景，不能用于推定音频和学习记录已经属于同步承诺。任何不执行或不适用项都记录依据，不能自动标为通过。

## 5 执行记录与缺陷处理

每次执行记录测试编号、需求编号、提交或构建、环境、资源与策略版本、输入、操作、预期、实际、状态和证据位置。音频场景需要实际播放核对，仅 HTTP 成功、文件存在或声音已枚举不足以通过。

状态采用未执行、通过、失败、受阻和不适用。受阻说明缺少的条件；不适用说明已确认的范围依据。缺陷关联失败场景与对应模块，修复后重测受影响场景，只有新的失败或未决问题才扩大测试范围。

模拟站点、模拟模型和规则测试的证据分别记录，与真实服务及桌面操作的结果区分。当前没有执行结果，后续按实际验证增量建立记录，不提前创建空白通过报告。

## 6 发布验收条件

- PRD 中 0.1 必需需求都有适用场景的执行结果。
- 支持矩阵、复习参数、同步字段与性能目标已明确，开放事项有确认结果。
- 关键数据错误、原声关联错误、重试虚增、假成功和静默同步覆盖已修复。
- 离线安装资源与冷启动实际验证，真实站点完成双向交换。
- 已知限制、未执行项及范围依据进入交付说明；不能靠缩减范围把必需失败项改为不适用。
