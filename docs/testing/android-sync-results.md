## 1 账号、环境和资料边界

用户恢复同步测试，并明确允许本次通过当前热点传输原声。手机为原 Mi 10 Pro／Android 13，升级 0.24.0，保留 Android Keystore 中原先真人批准的手机凭据及资料归属。真实连接检查成功，未重新登录、伪造身份或将电脑令牌复制到手机。

Windows 使用本仓库 `pnpm desktop:dev`，数据目录为 `.local/android-sync-desktop/Data`；只在这个具名隔离库中复用本机已有的获批桌面连接，同手机核对为同一账号。未启动或修改日常 `D:\SubtitleVocabularyList\Data`。服务器仍是现有英语练习站点，无本轮部署、协议或 schema 变更。

手机初始 6 个词条、6 来源、9 个原声缓存文件，总计 778599 字节，手动离线开启、自动同步关闭、6 个词条待发送。先保留业务库／WAL、原声、加密凭据的私有检查点，再按用户授权关闭手动离线。自动同步始终关闭。手机通过自己的 Wi-Fi 热点／VPN 访问服务器 HTTPS；没有 USB 网络 reverse 或手机直连桌面服务。USB 仅用于开发安装和观察。

## 2 本轮实现

- 计费网络默认继续等待；手机同步页显示本机原声总量及单次原声内容额度，用户主动选择“本次允许计费网络同步原声”才开始。上传、下载合计最多 20 MiB，额度只存在该任务的 HttpRemote 内存中，不保存为偏好、不继承给自动同步，任务结束／失败／取消即失效。
- 原声实际上传前计入字节，已有服务器原声仅核对不重复发送；下载先取得声明大小并扣除额度，继续沿用摘要、格式、完整保存和游标规则。不改变系统的计费网络标记或放开所有网络请求。
- 仍有词条／测试冲突、待发送资料或待关联记录时，不更新手机“上次完整交换”时间。原任务结果中的冲突数量继续可见，不用任务结束冒充全部处理完成。
- 原词库合并、原声／学习事实、增量／回执和冲突规则共用桌面 Rust 实现；没有另建手机协议或服务端。

## 3 已执行的最少正常流程

| 流程 | 实际结果与证据边界 |
| --- | --- |
| 真实手机连接 | 原批准连接检查成功，同账号归属不变；不是合成令牌或只看本地 connected |
| 首次手机交换 | 由实际手机页面的单次授权按钮启动；取得服务器资料并上传原先离线保存的 6 个词条。下载一份此前手机没有的独立原声；初始历史删除标记列为冲突，未静默删除资料 |
| 历史归档 | 仅处理 `svl-recovery-fixture-*` 和 `svl-large-history-fixture-*` 两个旧合成词条，沿用网站已有删除标记选择本地归档，保留全部资料／历史，没有恢复到在线普通词库 |
| 手机→服务器→桌面 | 隔离桌面取得手机词条、多义项及例句；reluctant 保持 5 条例句、5 次主动收录、原 correct 和修正后 correct_with_hint 及原因；forward 独立原声实际 HTML 音频播放约推进 0.52 秒 |
| 桌面→服务器→手机 | 桌面创建具名 `sync-proof-20261023` 合成词条及例句，手机取得相同 ID 与释义，不借桌面数据库或直连传输 |
| 服务器原声→手机 | 手机新下载原声时长 1710 ms，原生播放 position=327 ms、played=true、无错误；保留“原声”标识。不是仅验证 HEAD 或文件存在 |
| 同字段冲突 | 两端从同一基线分别编辑测试词条释义，手机取得 meanings.text 冲突，同时保留电脑端／手机端文字，localAttempts=1、remoteAttempts=0；通过实际界面选“保留本地文字，合并新增资料”后发送，未静默覆盖 |
| 手机新作答 | 测试词条按手机新释义完成一条词义回忆，得到 correct，收录次数仍为 1；该作答随正常冲突处理发送，不因重放另记成绩 |
| 最终收敛 | 手机与桌面均为 11 个未归档词条、cursor=43、pending=0、conflicts=0；专项协议状态为 assessment-1、cursor=7、pending=0、conflicts=0、pendingReferences=0。隔离桌面收到手机新释义和同一条正确作答；不以此宣称 Android P1 高频测试界面已实现 |
| 重复交换／原资料保持 | 修正后手机再普通同步，发送 0，处理 1 条自身已发送的版本通知；前后 7 个选定词条的完整采样事实一致。与首次交换前私有检查点核对，原 6 个词条的全部释义、例句、主动次数及 2 条旧作答／修正保持；测试词条仍为 1 次收录、1 条新作答，没有重复计数 |
| 双向原声内容 | 手机原声 `0e28510e…` 在桌面下载后与手机检查点字节完全一致；服务器旧原声 `a29c6c58…` 为 29535 字节，手机下载后 SHA-256 正确且与桌面同一文件完全一致。两个方向均已实际播放，未用回执代替媒体证明 |
| 最终构建与开发安装 | 统一版本、IPC、TypeScript／Vite、Windows 开发启动和 Android Rust／Kotlin debug 构建通过；手机升级后仍为原资料库，最终普通同步成功并更新完整交换时间。自动同步保持关闭，手动离线已按本轮授权关闭；未签名、发行打包或上架 |

完整同步过程中只补必要正常路径，没有执行容量、故障注入、兼容矩阵或长期测试。

## 4 证据与尚未覆盖

具名测试词条、服务器版本、手机与桌面库保留供检查；私有检查点、冲突双方快照、收录／历史快照和播放结果位于忽略的 `.local/android-sync-20261023`，不提交真实词库、账号标识、凭据、音频或模型。脚本用生产命令驱动合成测试记录，最终按真实内容及媒体播放判断；不以 HTTP 成功或拉取数量代替学习资料一致性。

首次桌面拉取包含账号的旧记录及水平测试历史；它们只按现有协议接收，不新增 Android P1 测试入口。测试驱动曾使用错误的 review_units 参数名，修正为既有 mode 参数后完成唯一一次作答；这是脚本问题，不记为产品失败或额外作答。

收尾修正 Rust 完成时间条件触发桌面开发热重载，中断一次最后拉取；编译后仅继续该次正常拉取，不将其当作主动故障验收。自动同步触发、计费网络额度用尽／拒绝／取消、断网恢复和其他设备没有扩展测试。本记录只覆盖 0.24.0 词库交换；AND-FR-22 的独立资料契约、0.25.0 站点版本 32 和真实剧集共享已另记 [专项结果](prepared-episode-results.md)，不属于词条包。
