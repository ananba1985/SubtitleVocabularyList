## 1 范围和环境

按用户要求后台开发，不启动桌面客户端、不操作鼠标、不播放声音、不触碰日常 `D:\SubtitleVocabularyList\Data`，不生成安装包。首个在线适配使用 [SubDL 官方 v1 契约](https://subdl.com/api-doc)，本机没有为本轮配置 API key，**没有发送实际搜索／下载 HTTP 请求**。

本轮只执行一次必要的下载后正常流程，不建立模拟 HTTP 服务，不执行故障、格式矩阵或扩展回归。输入为既有静音合成视频 `output/subtitle-import-acceptance/bilingual.mkv`（SHA-256 `61ca30970a37a44c059151e9de5afd7f1f02ce074af21f12f87e409cc443d457`），以及一个人工制作、包含 3 条中文字幕的 ZIP；候选的 SubDL 地址只是夹具元数据，不作为网络证据。

## 2 实际执行及结果

执行入口：`src-tauri/examples/online_subtitle_acceptance.rs`。隔离资料保留于 `output/online-subtitle-acceptance/Data`，结果在同目录上级 `result.json`。该入口拒绝重置已有命名资料；以后重新验证应使用新的 Data 目录。

```powershell
cargo run --manifest-path src-tauri/Cargo.toml --no-default-features --locked --example online_subtitle_acceptance -- output/online-subtitle-acceptance/Data output/subtitle-import-acceptance/bilingual.mkv output/online-subtitle-acceptance/fixture.zip
```

## 3 已接入的使用路径

1. “本地设置 → 在线字幕服务 · SubDL”保存用户自行取得的 API key，启用服务。密钥不需要发送到聊天中；配置默认关闭，留空保持已保存密钥。
2. “观看前预习 → 切换剧集 → 字幕资料”或“边看边学 → 学习设置”展开“在线补充中英字幕”，核对名称、年份、季集及语言后检索。可选启用导入后的自动缺失语言检索；候选仍由用户确认。
3. 核对剧名和发行版本，下载所选候选；多文件包明确选择文件，预览原文、时间和对应英文；有固定时间偏差可填写偏移。确认本集、版本和时间后导入。
4. 暂停优先采用已选中文；需要时在中文字幕偏移中校准。新增英文资产可“用于播放器”，继续使用 mpv 原生字幕／播放操作。
