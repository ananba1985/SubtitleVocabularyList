## 2 实际执行

为避免继续开发改变本次源码，从固定提交建立独立工作副本，在其中执行同一个根目录入口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\生成安装包.ps1 -SkipToolBuild -NoPause
```

`-SkipToolBuild` 仅复用本轮前两次已经重建的 OCR／Whisper／FFmpeg；播放器、底库、依赖许可及应用仍走正式准备／构建流程。此成功调用没有使用 `-CheckOnly`，也没有跳过干净源码和源码身份检查。

预检、Google／ECDICT 底库、固定 mpv 资源与 client API 2.6、331 项锁定依赖许可、Rust IPC／TypeScript／Vite、Rust release 编译（7 分 32 秒）、NSIS、独立运行目录、固定 SourceRef 的源码导出及 SHA-256 清单全部完成，根脚本退出 **0**。既有未使用导入及 Vite 大分块提示未阻止构建。

生成的完整目录已复制至主工作区 `release/0.26.5/`；执行记录保留在 `.local/package-logs/package-20261023-214709-253-143572.log`，核对记录为同目录 `package-20261023-214709-253-143572-verification.json`。临时工作副本及其复制的编译缓存随后回收，不占用正式 Data，也不清理共享工作区正在使用的构建缓存。
