## 2 用户提供的真实剧集

测试使用用户指定的 Modern Family S01E01 Pilot，并按用户要求复制到本项目的 `data/fixtures`。原文件与副本的 SHA256 相同：`40a2dc954680c0d4c2a32d3ab2217581562ed5de5b0d1638ac98b9fbea9d962f`。该目录已由 Git 忽略，未上传视频和导出的字幕音频。

| 检查项 | 实测结果 |
| --- | --- |
| 输入大小 | 321,416,957 字节 |
| 时长 | 1,379.454 秒 |
| 视频 | H.264，1280 × 720 |
| 音轨 | 英语 AAC，48 kHz，双声道 |
| 字幕 | 英语、法语、葡语、西语 PGS 图片字幕；没有可直接读取的英语文本字幕 |
| 英语 PGS 提取 | 20,121,538 字节的 SUP 文件 |
| 本地解码与 OCR | 938 个显示状态，取得 469 条带时间的文本字幕；未回退到语音转写，无处理警告 |
| 原型耗时 | 约 130.99 秒，包括信息检查、音轨处理、PGS 提取和 OCR |
| 时间校验 | 保存的片段均有正时长，位于素材范围内；最后一条结束于 1,377,836 毫秒 |
| 首段原声截取 | 2,921 至 4,631 毫秒，输出 AAC 片段时长 1,710 毫秒，可被 FFprobe 读取 |

首条字幕的识别文字已与解码出的字幕图像核对。其余字幕仍需通过预习纠错及抽样检查评估质量；469 条处理完成不等于全部文字无错误。

原型结果保存在本机 `.tools/episode-import` 的 `corpus.json`、`audio.m4a`、原始 SUP 与首段片段。此处仅记录可复核指标，实际素材与文本留在被忽略的目录。
