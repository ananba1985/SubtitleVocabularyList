SubtitleVocabularyList 是在 Windows 本机使用的英语单词本。用户在观看剧集前按词预习，在日常阅读时随时收录生词，并通过原声和主动回忆测验判断掌握情况。0.1 重点完成采集、确认、收录合并、复习、易忘词专项和已有在线单词本同步的完整使用流程。

## 1 背景与问题

用户正在通过英语剧集提高英语水平，以 Modern Family 等本地剧集作为学习素材。观看前需要识别自己尚不理解的词语，但逐句浏览所有对白耗时较长。现有单词本也难以同时保留剧集语境、原声和重复遇到同一生词的学习经历。

收录后的复习需要判断用户能否主动想起含义、能否从对白中听出目标词。只阅读释义或点击已经记住，不能充分反映掌握情况。用户同时已有英语练习站点，希望桌面单词本能够与其在线词库连接。

## 2 用户与产品目标

### 2.1 目标用户

0.1 面向在 Windows 本机学习英语的个人用户，使用本地剧集、阅读材料和已有英语练习站点。用户需要在无网络时完成主要学习流程，并在必要时使用联网查询与同步。

### 2.2 目标

| 编号 | 目标 |
| --- | --- |
| G-01 | 在观看前按单词和短语确认生词，减少预习耗时 |
| G-02 | 在剧集和日常阅读中收录单词、短语和整句，保存语境与可用音频 |
| G-03 | 重复收录时累积例句、原声和重复学习记录 |
| G-04 | 通过测验区分词义理解与听力识别表现，并据此安排复习 |
| G-05 | 对反复遗忘的词进行专项练习 |
| G-06 | 离线完成核心功能，并与已有在线单词本同步 |

0.1 不预设未经验证的识别准确率、每日学习数量或语言能力提升指标。需要量化的性能和学习参数见待确认项。

## 3 版本范围

### 3.1 纳入 0.1

- 单个本地剧集文件或文件夹导入，取得可用字幕、对白和音频。
- 无可用文本字幕时的本地语音识别，以及识别结果纠错。
- 按单词和短语浏览候选内容，用户确认熟悉、收录或暂不确定。
- 全局划词与截图 OCR 采集，以及收录前确认。
- 单词、短语和整句收录，语境释义、来源、例句和原声保存。
- 重复词条合并，多例句、多音频和重复收录记录。
- 自由浏览与按计划测验复习，分别记录词义和听力表现。
- 易忘词专项。
- 本地翻译与解释，按需联网查询，无原声时的 Windows 本地英语语音兜底。
- 与已有英语练习站点的在线单词本同步。

### 3.2 后续再规划

高级每日负荷控制、批量熟词管理、复杂标签与统计、音频播放清单、完整备份与导出功能等不纳入本次 0.1 功能承诺。移动端、多用户协作和插件市场也不属于当前范围。

### 3.3 产品边界

本产品独立运行，用户无需同时启动已有取词软件。对已有英语练习站点的扩展仅服务于词库集成，不在本版本重新建设该站点的其他学习功能。

## 4 术语与业务概念

| 术语 | 定义 |
| --- | --- |
| 词条 | 用户收录的单词、短语或整句 |
| 候选项 | 从素材中整理出、等待用户判断的词或短语 |
| 例句 | 词条出现时的原始句子及对应语境释义 |
| 原声 | 来源素材中的真实对白音频，与系统生成语音分别标识 |
| 来源出现 | 某词在剧集或阅读素材中出现的记录，反映素材中的出现情况 |
| 主动重复收录 | 用户再次确认将已有词条加入单词本，反映重复学习或遗忘经历 |
| 熟悉 | 用户在当前语境下认为理解该候选内容 |
| 我已掌握（默认跳过） | 用户主动建立的本机全局筛选偏好；跨来源隐藏相同类型和词形，不产生测验成绩，可撤销 |
| 掌握状态 | 根据学习与测验记录维护的状态，不由是否已收录直接决定 |
| 易忘词 | 多次测验失败或反复主动收录，需要增加针对性练习的词条 |

## 5 主要用户流程

### 5.1 观看前预习

1. 用户选择一个剧集文件或文件夹。
2. 系统取得对白与音频，整理按词浏览的候选列表。
3. 用户按单词或短语确认；需要时展开原句、释义并播放对白。
4. 用户收录需要学习的内容，系统保存例句、原声及来源；已存在的词条按合并规则处理。
5. 用户完成本次预习，再观看剧集。

### 5.2 日常划词与 OCR 收录

1. 用户在其他应用中选中文字并触发取词，或截图选择需要识别的区域。
2. 系统显示取得的文字，用户核对目标词、例句和释义。
3. 无法自动取得完整上下文时，用户可补充；识别错误时，用户可修改。
4. 用户确认收录，系统执行与剧集收录一致的合并规则。

### 5.3 测验复习

1. 用户打开按计划安排的复习内容。
2. 系统出示词义回忆题或听力题，作答前隐藏答案。
3. 用户回答；系统记录正确、使用提示或错误，以及对应能力维度。
4. 系统据此更新复习安排；存在判分歧义时，用户可以纠正。
5. 多次失败或重复收录的词进入易忘词专项，按薄弱点继续练习。

### 5.4 在线词库同步

1. 用户在需要时连接已有英语练习站点。
2. 系统交换需要同步的词条内容，并按合并规则处理已有内容。
3. 同步成功后显示结果；网络、认证或服务异常时保留本地修改，用户可稍后重试。

## 6 功能需求与验收标准

本节需求均属于 0.1 必需能力。验收描述是实现后的验证依据，当前不表示功能已完成。

### FR-01 剧集导入与对白准备

**需求**：系统应支持导入单个本地剧集文件或包含多个剧集的文件夹，取得对白文字、时间位置和音频。应优先利用可用文本字幕；无可用文本字幕时，应支持本地语音识别并允许用户纠错。

**验收标准**：

- 导入有可用字幕的素材后，能够浏览对应对白并播放关联音频。
- 导入无可用文本字幕的素材，在本地识别资源准备完成后能够生成可编辑的对白文字和时间位置。
- 文件夹中的剧集具有独立的处理结果；某个文件失败时，已完成内容仍可使用，失败原因可见。
- 图片型或不可读取的字幕不会被当成已成功提取的文本；系统提供可用的本地识别路径或说明处理失败。

### FR-02 按词确认生词

**需求**：系统应按单词和短语展示候选内容，在同一剧集内合并重复展示项。用户可标记熟悉、确认收录或暂不确定，并按需查看例句、语境释义和对白音频。

**验收标准**：

- 默认确认单位是单词或短语，用户无需逐句审核全部对白。
- 同一词的多处出现可以从同一候选项查看，不丢失来源例句。
- 已收录但尚未掌握的内容仍可提示用户判断；已收录不等同于已掌握。
- 对当前语境的熟悉判断不会自动推断为理解该词所有其他含义。
- 用户可另行标记“我已掌握”，同类型、同词形的内容在本机已有和未来剧集默认隐藏；可显示已掌握内容、搜索管理并撤销标记，恢复无需重新导入。
- 标记不删除原句、原声或学习历史，不增加测验正确记录；再次明确收录后恢复展示并沿用原有复习优先规则。

### FR-03 划词采集

**需求**：系统应支持用户在其他应用中通过全局操作获取所选文字，并进入收录确认流程。自动获取上下文的范围应如实显示，允许用户补充例句。

**验收标准**：

- 在明确支持的应用中，触发取词能够显示本次选中文字。
- 获取失败、未选中文字或取消时，不会自动收录旧内容。
- 用户可以核对或修改内容后再收录；支持应用清单在实现验证后确定。
- 所选目标已标记“我已掌握”时，默认跳过收录窗口，保留“仍要查看”的显式入口；未知目标继续原确认流程。

### FR-04 截图 OCR 采集

**需求**：系统应支持选择屏幕区域并在本地识别文字，识别结果可编辑，并进入统一收录流程。

**验收标准**：

- 网络断开且本地识别资源准备完成时，截图识别仍可运行。
- 用户可以修改识别文字或取消操作。
- 识别目标完整内容及类型命中“我已掌握”时默认跳过确认窗口，可主动查看；句子中出现熟词不会删除原句中的文字。
- 截图、裁剪或识别失败不会使用上次截图的结果完成本次收录。
- 在声明支持的屏幕缩放和多显示器场景中，识别区域与用户选择区域一致。

### FR-05 单词短语与整句收录

**需求**：系统应支持收录单词、短语和整句，保存原文、语境释义、例句、可取得的来源和音频。应保留自动识别或解释内容的人工纠错能力。

**验收标准**：

- 三种内容类型均可收录、重新打开并浏览。
- 例句中的词义与该次来源关联，新的语境不会覆盖旧释义。
- 用户明确将同一例句关联到新的释义或解释时，各条已确认语境均保留，复用原句与已有原声，不因关联新增而复制媒体。
- 不存在完整来源或音频的内容仍可收录，缺失情况如实显示。
- 用户纠正后的内容在重新启动应用后仍然保留。

### FR-06 重复收录与合并

**需求**：系统应支持将已有词条再次收录，追加新的例句、释义和音频，保留旧内容和学习历史。应区分来源出现与用户主动重复收录。

**验收标准**：

- 同一词条从新的对白再次收录后，能够同时浏览旧例句与新例句。
- 相同来源片段重复加入时，不产生重复例句或重复音频副本。
- 用户新的主动重复收录可增加相应记录；自动导入重试和同步重试不会冒充一次主动收录。
- 再次收录不会清空测验历史；已掌握的词再次收录后，应重新提高复习优先级。
- 可能对应不同含义或不同内容类型的条目，不进行不可纠正的盲目合并。

### FR-07 原声保存与本地语音兜底

**需求**：有来源音频时，系统应保存与收录例句对应的原声，供日后复习。没有原声时，应能使用 Windows 本地英语语音朗读词条或例句，并标明音频类型。

**验收标准**：

- 剧集收录完成后，即使原剧集文件被移动或删除，已保存对白仍可播放。
- 原声播放内容与所示例句对应，用户可以识别字幕或截取位置需要纠正的情况。
- 无原声且已安装本地英语语音时，断网仍能朗读。
- 原声和系统生成语音具有明确标识，不把生成语音标记为来源对白。

### FR-08 本地解释与按需联网查询

**需求**：系统应接入用户已有的本地大模型服务，生成语境释义与例句解释；用户需要时可进行联网查询。

**验收标准**：

- 外网断开、本地服务可用时，能够取得语境释义和解释。
- 本地服务不可用时，用户仍能浏览和复习已有内容，并收录原文后补充释义。
- 自动生成内容可人工修订。
- 联网查询由用户操作或明确启用的设置触发；失败时不丢失当前收录内容。

### FR-09 自由浏览与复习

**需求**：系统应支持按词浏览已收录内容，自由查看多条释义与例句，并播放对应音频。自由浏览与按计划测验同时保留。

**验收标准**：

- 用户可选择词条查看其已有例句和音频。
- 自由浏览不要求先完成测验，也不会仅因看过答案就自动记录为测验正确或已经掌握。
- 同一词条的原声和释义具有清晰的对应关系。

### FR-10 测验与复习安排

**需求**：系统应通过主动回忆测验评估掌握情况，支持词义回忆和原声听力相关题型，并分别记录词义理解与听力识别表现，根据结果安排后续复习。

**验收标准**：

- 作答前隐藏相应答案；听力题在需要时隐藏字幕，播放对应音频。
- 正确、使用提示和错误得到不同记录，错误或需要提示的内容较早再次复习。
- 多次间隔测验通过后可延长复习间隔；不能仅靠自由阅读延长间隔。
- 含义相近且符合语境的回答可被接受；用户可修正有歧义的判分。
- 词义与听力表现分别保留，避免一次词义题正确掩盖听力困难。
- 测验和复习安排在离线条件下可执行，不强制依赖在线服务或可用的大模型。

### FR-11 易忘词专项

**需求**：系统应根据多次测验失败和主动重复收录识别易忘词，区分词义、听力或短语使用等薄弱点，提供针对性解释和练习。

**验收标准**：

- 满足专项规则的词条能够进入专项列表，用户可查看进入原因。
- 某词多次词义回忆失败时，能够增加词义相关练习；听力薄弱时能够使用对应音频练习。
- 再次练习保留原来的例句和测验历史。
- 本地大模型可辅助解释，但其不可用不会阻止基础专项练习。
- 触发与退出规则在实施前明确并记录，具体阈值不由本文臆定。

### FR-12 在线单词本同步

**需求**：系统应与用户已有英语练习站点的在线单词本双向同步词条、释义、例句、原声音频和学习记录，使桌面新收录与学习内容可同步到站点，并将在线已有内容合并到本地。完整同步范围已经用户明确确认。

**验收标准**：

- 在真实站点连接与认证成功后，可完成本地新增到在线、在线新增到本地的完整流程。
- 重复同步不会产生重复词条、重复例句或重复主动收录计数。
- 离线修改可保留，恢复连接后能够继续同步。
- 认证失败、网络中断或服务异常时，本地词库和学习功能仍可使用。
- 两端存在冲突修改时，不静默覆盖用户内容；具体处理规则进入同步设计。
- 词条、释义、多例句、原声和学习记录均须在两端保留正确关联；实际接口字段、认证与版本规则在同步设计中明确，不能因现有站点字段不足缩减已确认范围。

## 7 数据与业务规则

| 编号 | 规则 |
| --- | --- |
| BR-01 | 已收录、当前语境熟悉、自评已掌握的筛选偏好、根据测验掌握，是不同概念 |
| BR-02 | 一个词条可有多个例句、语境释义和音频；再次收录以累积内容为目的 |
| BR-03 | 来源出现次数与主动重复收录次数分别统计 |
| BR-04 | 相同内容的任务重试、同步重试与用户明确再次收录，应能够区分 |
| BR-05 | 保留原始文本与来源；规范化和合并结果可由用户纠正 |
| BR-06 | 原声与生成语音分别标识，例句与音频保持对应 |
| BR-07 | 复习状态按测验维度维护，判分修正保留记录并反映在后续安排中 |
| BR-08 | 联网查询和同步属于可选连接；本地使用不要求在线登录 |

需要保留的信息包括词条原文与类型、语境释义、例句、来源与时间位置、音频类型及关联、主动收录记录、测验结果和复习状态。具体结构与存储方式由架构和详细设计定义。

## 8 非功能需求

| 编号 | 需求 | 验收依据 |
| --- | --- | --- |
| NFR-01 | 核心流程离线可用 | 本地资源准备完成后，在无外网环境完成导入、OCR、收录、播放和基础测验；大模型扩展按本地服务可用性执行 |
| NFR-02 | 数据保存与关联完整 | 已确认保存的词条、例句、原声和学习记录在正常重启后可用；中断和重试不制造错误关联或重复操作 |
| NFR-03 | 后台任务可观察且不阻断主要操作 | 导入、识别和解释有明确状态，用户可取消进行中的处理；全部未结束任务可见，已结束任务默认只展示最近一条。历史默认折叠并可分页查询更早记录；可取得的处理对象、时间、结果和失败原因可见，已保存内容仍可浏览 |
| NFR-04 | 外部服务失败可独立处理 | 本地模型、联网查询或同步异常，不阻止已有词库浏览、音频播放及基础复习 |
| NFR-05 | 本地资料按需联网 | 剧集、截图、原声和个人词库不在本地处理过程中自动发送到外部服务；联网查询与同步的数据范围明确 |

兼容的 Windows 版本、文件格式、屏幕配置和可接受的处理耗时，在技术验证后形成明确的测试矩阵。本文不将未验证的全平台或全应用兼容写成承诺。

## 9 外部依赖与约束

- 用户提供合法可用的本地学习素材。
- 本地识别和语音资源需要在离线使用前准备完成。
- 本地解释能力使用用户已有大模型服务，具体接入配置由架构文档定义。
- 在线同步依赖现有英语练习站点提供桌面可用的认证和数据接口，需要对站点进行必要扩展。
- 来源音频的可用性影响听力题；无原声时可以使用已标识的系统语音。

## 11 0.1 整体验收

0.1 发布时，应有执行证据表明本节场景和第 6、8 节的验收标准已满足，失败项与限制如实列出。

| 场景 | 验收结果 | 关联需求 |
| --- | --- | --- |
| 导入一集有字幕剧集并完成预习 | 按词确认，收录生词与原声，重新启动后可以复习 | FR-01、FR-02、FR-05、FR-07 |
| 本地处理无可用文本字幕的素材 | 取得可纠正的对白与时间位置，并完成收录 | FR-01、NFR-01 |
| 从阅读应用划词以及截图收录 | 本次文字正确进入确认流程，取消与失败不误收旧内容 | FR-03、FR-04、FR-05 |
| 再次遇到已收录词 | 累积新例句与音频，保留历史，区分重复收录与重试 | FR-06、FR-07 |
| 完成词义与听力测验 | 两类结果独立记录并影响后续复习，可修正歧义判分 | FR-09、FR-10 |
| 对易忘词进行专项练习 | 原因可见，练习针对薄弱点，历史持续保留 | FR-11 |
| 与已有站点交换词条 | 两个方向均在真实账号下完成，重试不重复，本地异常隔离有效 | FR-12、NFR-04 |
| 无外网使用 | 核心流程可用，联网功能失败不破坏已有内容 | NFR-01、NFR-02、NFR-04、NFR-05 |
