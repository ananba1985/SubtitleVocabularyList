## 1 设计决策与模块边界

| 决策 | 本次方案 | 原因 |
| --- | --- | --- |
| 独立领域 ARC-10 | 水平测试独立保存配置、题库、会话、作答和报告；不直接调用 review_submit 更新排程 | 现有学习单元绑定已收录词条，摸底需覆盖未收录内容，且不应改变原学习状态 |
| 复用现有能力 | React/Tauri、Rust Application/Store、TaskManager、ModelGate、Windows 语音、媒体服务和收录事务 | 不增加技术栈，不另建模型并发池或第二套收录合并规则 |
| 冻结测量依据 | 已发布题库不可变，会话开始时冻结题目、答案、选项顺序和评分策略 | 题库更新、恢复和同步后仍能重现原测试；前端仅取得当前阶段可见字段 |
| 参考数据与个人记录分开 | 词频索引属于只读底库；题目草稿、会话及历史在独立 assessment 表中 | 更新安装底库不覆盖个人作答，题库生成不自动建立生词 |

建议模块：`assessment_bank.rs` 管理来源、准备、核对和发布；`assessment.rs` 管理配置、抽样及会话；`assessment_reports.rs` 管理判分投影、报告和历史；`assessment_sync.rs` 适配完整会话交换。前端采用 `AssessmentView`，划分配置、答题和报告组件，共用 `src/types.ts` 与既有 IPC 包装。文件名是实施位置提案，不据此建立空文件。

后台准备通过既有 TaskManager 聚合；交互音频和读取保持现有轻量方式。题库准备复用全局模型并发、批大小、取消及重试策略，不修改本地模型服务启动参数。启动仅加载概要，不扫描全题库、生成音频或连接模型。

## 2 词频目录与题库资料

### 2.1 完整排名索引

当前 `prepare-base-dictionary.py` 只把含中文的 Google 行写入 dictionary_entries，因此该表不能充当完整 Top N。后续在 Google `base.sqlite3` 增加以下只读参考表，底库 schema 提议升为 2；dictionary_entries/aliases 保持兼容，ECDICT 仍为 schema 1。

| 表 | 关键内容与约束 |
| --- | --- |
| frequency_catalogs | catalog_id、word/phrase、来源 URL/提交/摘要、排名单位、原始行数、最大排名和来源说明；同一来源版本不可变 |
| frequency_targets | catalog_id、原排名、原文、查词键、明确词元键及映射依据；保留没有中文或尚不可出题的目标，不重新连续编号；同目录内排名和目标身份可核对 |

单词沿用已固定的 Google 来源；ECDICT 只补释义，不把其排名混入 Google。组合目录须在 M-15 核对真实来源、排名口径、固定版本和自然搭配筛选；没有合格资料时明确 `not_ready`，不以现有词典短语或任意 n-gram 补齐。不同目录的 rank 只在自身内比较，混合测试分别显示范围。

Top N 首先选原排名不超过 N 的目标，再统计明确屈折归并后的词元、合格题目及缺项。词元仅依有依据的映射归并，不猜测词根、不合并派生词；归并目标沿用其组内最小原排名定位频段，并保留原始成员。单词和短语使用不同身份空间，来源版本变化不改写旧会话。

M-15 已固定组合来源为 [Norvig 公开双词频次子集](https://norvig.com/ngrams/)，文件 SHA-256 为 `781c0596c3eea532d30bef9f3dba1d5137d652f00376260822c761a7584dfb8c`。按频次降序、同频原文排序确定原排名；286,358 条双词记录只作频次依据，初始仅筛选 20 条自然短语，整体释义与例句由项目自拟。其余 n-gram 不作为合格短语，候选题仍须核对。来源页面的 MIT 声明针对代码，不能据此宣称整个语料也获得 MIT 许可；不把完整 Google/LDC 语料纳入源码。

### 2.2 准备、核对与发布

准备链路为“选目录/范围/题型 → 复用通用释义 → 形成候选题 → 核对 → 发布版本”。底库命中不重新请求模型翻译；已有解释是候选材料，不能把个人语境义或一条简译机械设为唯一答案。本地模型仅辅助缺失解释及题目生成，答题与判分不调用模型。

每题保存目标身份/原排名/频段、题型/维度、考查义项、题干与语境、选项稳定 ID、可接受答案、讲解、来源及音频描述。辨识题的干扰项需同类且可区分；填空采用自然语境及已核对变体；功能词考句中用法。组合有整体含义及自然例句，不拼接单词释义。

草稿状态为 `draft → needs_review → approved/rejected`；同一用户可承担核对，不要求额外管理系统。结构/答案可区分检查通过后仍须在管理入口确认题干、语义、答案和音频依据，才可 approved。管理及来源明细在高级面板，默认测试页只呈现是否可测。发布把 approved 项固定为只读 bankVersion；新增或修订另建版本，未通过项保留原因且不计入可用题量。

首版每个“目录目标＋题型＋明确义项”只准备必要题目，不按每个剧集对白笛卡尔展开。任务分别报告目标词元数、题目准备项数、已生成/待核对/批准/未完成题数；进度单位标为题目准备项，不能把题数称为词数或 HTTP 次数。已保存准备项复用，取消保留进度；用户取消后不自动重启，意外退出恢复沿用持久化任务规则。进度只放后台任务页。

系统语音题在发布前准备可播放的本地英语资源，描述包含文本、声音及参数；真实原声引用已有媒体摘要和片段。现场播放失败不计错，允许恢复或明确跳过。只读参考目录及其来源说明随未来安装包更新；个人题库和会话不作为安装资源，也不在每次启动重新生成。

## 3 初始参数与确定性抽样

以下是可实施的初始设计建议，**尚未校准，也不是英语等级标准**。OPEN-07 不因写入提案自动关闭；M-15 核对实际题量后记录采用值，所有策略值随 policyVersion 保存。

| 参数 | 初始建议与调整方式 |
| --- | --- |
| 快速摸底 | 单词 Top 3000、30 题、三个题型等额；开始前显示并允许修改 N、题量、内容和题型 |
| 指定范围 | Top 1000/3000/5000 及自定义正整数 N，最大值取实际目录范围；单词和组合分别配置 N |
| 频段 | 每 1000 个原排名为一段，最后一段截到 N；不把中文缺项重新排序补满 |
| 抽样配额 | 所选内容类别等额，再在其频段、题型内等额；余数用固定次序分配并在预览明示，题型至少有一题；题量不足时要求调整 |
| 近期重复 | 优先避开本机最近 7 天的已测词元；不足时在原频段补入并明示重复量，不跨段替换；历史记录不因偏好而删除 |
| 样本不足 | 报告单元有效题数少于 10 时显示样本不足，只报告题数和实际结果，不作掌握结论；即使达标也不换算精确词汇量 |

预览只读计算 eligible 集合和配额，返回目录、题库及 inventoryRevision、缺额和警告，不返回答案，也不消耗题目。可用集合由来源范围、approved 题目和所需资源决定，**不读取个人已掌握标记或复习到期状态来排除熟词**。另显示缺题目标比例；覆盖未齐时测试及报告标明“所选 Top N 范围内已准备题目抽样”，不能将此子集描述成完整范围的代表性测量。配额本身不足时禁止开始，不以范围外词补足。

开始时校验预览版本，核心产生 seed，在“内容类别 × 频段 × 题型”配额内按随机优先序做无重复分配，同一明确词元在一场测试中只占一个位置。实现须检查完整配额可满足，不能只贪心取前若干项后静默缩量；不足返回具体层和数量，用户调整后重新预览。选项顺序独立随机并冻结。保存 seed、实际项目、来源、配额、重复标记和策略，重开不重新抽题。

M-16 实际采用增广匹配完成全部配额，同类词元在所有题型间只占一个位置；先分配非近期目标，不足再在原频段补入。余数在固定内容／频段顺序中轮转分配给题型，避免小配额总落在首题型。预览分别返回 planned、available、unfilled、覆盖与重复提示，存量已掌握状态不参与筛选。开始事务内再次核对 inventoryRevision，冻结 seed、来源、配额、实际题目、选项和 assessment-score-1。选项原 ID 替换为每场不含答案含义的稳定 ID，题序和选项序均冻结。

## 4 交互与会话状态

新增主导航“水平测试”。首页以快速开始、范围摘要和继续未完成测试为主；配置编辑、题库准备/核对、来源和历史默认收起。组合未准备时说明状态，用户可自行改测单词，不暗自切换。

答题区主要显示题干、作答、进度和暂停；听力题显示播放操作，不下发英文目标、字幕或答案。区分回答、标为不确定、需要提示和“不知道”。讲评在该题提交后开放；整场题目词元不重复，尚未作答项目的私有字段不随讲评返回。

| 状态 | 进入与后续 |
| --- | --- |
| active | start 原子保存整场快照；允许作答、音频、暂停或提前结束 |
| paused | 显式暂停；重开可按原题、原答案和位置继续 |
| completed | 所有计划位置均已有作答或明确跳过；另示有效题量，未计分题不冒充答对 |
| ended_early | 用户提前结束，报告标注未完成和已处理范围，不补造未答成绩 |

题目位置状态为 pending/answered/skipped；作答结果另分 correct/incorrect/unknown/needs_confirmation，附 uncertain、hinted、audioStatus。音频未播放成功的听力项目跳过后标记 unscored_audio，而非错误。全部题已处理但有待确认判分时，会话可 completed，报告为 provisional；待确认清零后为 settled。

普通题主动略过按 unknown 计分，不能用“跳过”排除不会的题来抬高正确率；只有核心确认资源不可用或明确认定题目无效时才进入未计分项。提前结束仍保留未答量。提示返回前持久化 hinted，重听只更新播放事实，不生成另一条作答。

音频准备成功与实际播放分开记录。核心下发关联会话/题目的 playbackId，播放器回传 started/ended/error 及进度，核心只接受当前关联；正常播放回执用于听音提交条件，准备文件本身不作为已播放证明。该回执证明播放器事件而非人的听感，真实声音仍按 TC-55 记录。

答案与进度在同一事务提交，operationId 和请求摘要用于重试回执；同一位置不能因重开重复增加作答。已提交答案修改走追加修正，不能覆盖原回答。意外退出恢复已提交事实，未提交输入可保存为草稿，不伪装成作答。会话恢复和暂停状态不触发原复习调度。

## 5 判分、报告与复测

辨识题按选项 ID；填空使用当前已核对答案集，规范化仅处理明示的大小写、空白和等价字符，不无条件去掉有意义标点或做模糊拼写猜测；未匹配的非空回答进入 needs_confirmation。unknown 为用户明确不知道。听音识义可采用选择或已核对短答，保留回答形式，不把辨识题记成主动拼写能力。

人工修正可确认正确/错误、补充使用提示事实、撤销有问题题目的有效计分；保留理由、原结果和版本，不支持把已使用提示的记录静默清成无提示。题目问题进入后续核对，不因一次报告自动删除全库题目。原题快照不修改，报告产生新修订。

报告按频段、内容类别和能力维度分别汇总，默认呈现这些独立视图；细分交叉明细按需展开。每个报告单元采用固定口径：

- P 为计划题量，A 为已处理位置数，U 为其中未计分量（未播放/无效/待确认等）。V 为可计分量，包含 correct、incorrect、unknown；A=V+U，未答量为 P-A，未答题不混入分母。
- C 为有效正确量；答题正确率为 C/V，V=0 显示暂无有效结果。另列无提示且确定的正确量 C0 和 C0/V，不能用 C 掩盖提示或猜测；不确定、提示、unknown 数分别可查。
- 不知道和有效错误留在 V，不能通过排除错误提高比例。invalid 等项目显示排除原因；修正后重算对应报告，旧修订可追溯。
- 主结论为本次抽样表现及待巩固项。低覆盖、低样本、提前结束和重复题明示；不计算 `Top N × 正确率` 的词汇量，不映射 CEFR 或其他考试等级。

历史使用固定排序和分页（建议每页 20），报告默认折叠逐题详情。比较键包括目录版本/排名单位、内容及 N、频段边界、题型构成与评分策略；相同键时也显示实际样本和重复情况，只说可比配置下的表现变化。键不同只作并列展示，显示差异，不宣称同尺度提升。复测复用原配置进入预览，仍重新抽样，来源或题量变化先确认。

## 6 数据模型与事务提案

个人数据仍在当前安装目录的 `Data/vocabulary.sqlite3`。009_assessments.sql 已新增 schema 9 的基础表，不复用 review_attempts/review_states 保存水平测试。M-15 已使用题库、题目、准备检查点与操作回执；会话／题目快照／作答／修正已接入 M-16 核心，报告／收录关联已由 M-18 接入；同步表仍是 M-19 实现基础。原词条、解释、媒体、原复习及同步记录保持。

| 表 | 关键字段／约束 |
| --- | --- |
| assessment_banks | id、version、catalog_refs_json、builder/policy 版本、draft/published 状态、准备范围；发布版本不可变 |
| assessment_preparation_targets | bank／目录／词元检查点与失败原因，重新准备复用已保存候选题 |
| assessment_operations | operationId、请求摘要及原始回执；设置、审核、发布及准备定位的幂等事实 |
| assessment_items | id、bank_id、目标/词元/排名、内容类别、题型/维度、义项、公开题干、私有答案及解释、音频描述、核对记录；发布后修订进入新版本 |
| assessment_sessions | UUID、start_operation_id、request_hash、config_json、bank/目录/策略版本、seed、状态、revision、来源设备和时间 |
| assessment_session_items | session_id、ordinal、item_id、词元、频段/维度、完整私有快照、选项顺序、重复标记、位置状态；unique(session_id,ordinal) 与会话词元唯一 |
| assessment_answers | UUID、session_item_id、operation_id、request_hash、原回答、结果、uncertain/hinted/audioStatus、评分版本和时间；位置只有一个原始提交 |
| assessment_corrections | UUID、answer_id、operation_id、expected_revision、结果/有效性/理由、修订时间；追加历史不覆盖原作答 |
| assessment_report_versions | session_id、report_revision、来源事实修订、report_json、created_at；缓存投影可重建但旧报告修订保留 |
| assessment_collection_links | session_item_id、collection_operation_id、entry_id、报告修订/来源；只在用户确认收录后建立 |
| assessment_sync_accounts | account_scope、assessment_cursor、能力及最近状态；与已有词条游标分离 |
| assessment_sync_state | account_scope/session_id、本地修订、远端基准、冻结请求/摘要/changeId、回执、完整冲突副本；未回执请求不被新本地修改覆盖 |

配置偏好放入既有 settings 的独立 assessment 命名空间，不改现有模型/语音/复习配置。生成音频复用媒体服务，路径位于 Data/media 下，题目只存相对描述/摘要；临时模型输出进入 Data/jobs，不写 AppData。

会话内部的题目、作答、修正与报告有本地关联约束；bank/item 的来源版本引用允许接收端未安装该题库，以会话完整快照复现历史，不要求导入整库，也不把收到的题目自动发布到本机可抽样题库。收录关联由实际词条实体映射确认，未到达时保持待关联状态。

开始会话、提交作答、追加修正及报告修订分别使用短事务，不把模型、音频生成或网络等待放进 SQLite 事务。完成收录时扩展既有收录事务接受可信的 assessment 来源，在同一事务写收录回执与 association；不另写一套词条合并。多目标逐项保存并返回明细，不承诺整批原子成功；每目标操作标识稳定，部分成功后重试只处理未完成项。

## 8 与收录、复习及完整同步的关系

查看报告、答错或修正均不触发 collection_commit、已掌握标记或复习投影。确认后按 CMD-59/60 复用 FR-05/06；测试例句来源显示“高频水平测试／题库版本”，原声与系统语音分别标注。取消不保存词条，返回仍定位原报告；再次明确收录才沿用原复习优先规则。

新增 `assessment-1` 完整会话包提案，拟在 `protocol/svl-assessment-1.json` 定义，**本轮不创建此文件或更改 svl-sync-1**。包根为 session UUID，而非 entryId。包含目录/题库/评分版本、配置及配额、实际抽中题目完整快照、原作答、提示/音频状态、全部修正、报告版本及确认收录关联；不只上传总分。

只同步这场实际用到的快照，不同步整份词频表、整库题目草稿、模型地址、凭据或本机路径。实际使用的真实原声沿用摘要媒体传输；系统语音字节仍是本机缓存，保存可重建的文本、声音描述及原音频类型/播放事实，重建失败不改变旧成绩。

站点能力提案 `assessmentSync=assessment-1`；新增会话 changes/get/put 命名空间，认证、冻结回执、冲突及大包分片复用现有机制，独立游标，不修改旧词条包结构。完整包按账号事务应用后才推进游标；相同事件 UUID 同内容去重，不同内容保留冲突。并发修改按共同基准合并无冲突追加，同一作答/修正矛盾保留完整两份待选，不按客户端时间静默覆盖。没有跨设备实时协作或分布式锁需求。

确认收录的词条及真实原声先按旧协议交换，会话引用用既有实体别名重映射；引用尚未到达时保留待关联及未完成状态，不据此新增词条或丢掉引用。收到历史不调用收录/复习命令。站点未支持时仍可同步现有词条，但显示“水平测试记录待站点支持”，不能显示所有学习资料已完整同步。站点具体表和路由在 M-19 核对其实际源码后落实到契约，不能仅用本地夹具宣称站点已接通。
