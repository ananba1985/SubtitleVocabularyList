## 2 本版功能

支持视频/目录导入、字幕和本地转写、音轨/字幕选择、外置字幕、按词预习、修订和收录；词、短语与整句共用合并规则，保留多语境和独立原声。

支持全局划词、截图 OCR、可编辑确认与采集队列；本机 Qwen 解释、手动在线词典/翻译和 Windows 英语声音；自由浏览、词义/听力测验、提示、判分修正、历史和易忘词专项。

与现有英语练习站点双向同步词条、释义、例句、原声和学习记录；包含完整大资料传输、重试、明确冲突处理及归档保留。断网及服务失败时，本地学习仍可继续。

本次收尾修复了目录与显式文件重复处理，以及旧未结束任务被最近 30 条历史挤出的问题。后台列表保留全部未结束任务，用户可观察、取消，退出时也会清理这些任务。

用户试用后的本轮修订修复了长词表下方选词时右侧详情滚出窗口的问题。预习和词库的详情保持在窗口内，较长内容可独立滚动，切换词条后回到详情顶部；悬停与选中样式区分，旧的语境和试听请求不覆盖当前选择。

后台任务默认展示全部未结束任务与最近一条已结束任务。历史默认折叠，展开后每页 10 条并可查看更早记录；卡片补充对象、时间、用时和结果，批量导入明细按需展开。听力题摘要保持答案隐藏，任务页不提前展示待作答目标。

新增“我已掌握，以后跳过”：本机已有和未来剧集的同类型/词形目标默认隐藏，划词/OCR 命中完整目标时默认跳过确认，保留“仍要查看”；候选可显式显示，设置中可搜索分页恢复。不同词形分别标记，原语料与历史保留，新的明确收录恢复展示。此功能是本地筛选偏好，未将手动标记计为测验成绩，未增加站点偏好同步。

本轮 71 项核心测试通过、0 失败；3 项依赖独立后台或真人批准凭据的测试默认忽略，对应真实 HTTP 和大资料交换的前轮执行记录保留。格式、全目标 Clippy、前端生产构建及 Windows Release/NSIS 通过。新增核心测试覆盖数百条终态分页、旧快照、对象重启保留和原声关联；实际生产组件的默认摘要、25 页历史、迟到响应、失败重试、取消、500 个视频汇总和听力答案隐藏见[任务界面记录](../testing/desktop-import-results.md#6-用户验收发现的任务历史展示修正)，没有冒充本轮真实导入了 500 个视频。此前长词表详情验证见同记录的第 5 节。本轮全局标记的跨来源过滤、原子恢复、旧回执重试和重启保持有真实核心测试；生产前端的标记、撤销、45 条管理分页、采集跳过与草稿保持、主动查看和再收录见[已掌握筛选记录](../testing/desktop-import-results.md#7-全局自评已掌握筛选与采集跳过)。本轮未重跑 OS 跨进程取词与截图焦点操作，保留原兼容范围。

本轮包静默实装退出 0，程序按 NSIS 标记核对一致，六项资源匹配；安装后主程序 SHA256 为 `7b6cf3fd69fa788f7096c5d88052a9685696f851ca278d038bbe294150405466`。1073 个源码材料摘要、131 个应用文件的 Git 树、316 份 Cargo、8 份工具源码和 321 项条款一致。覆盖用户正在使用的原程序目录后，正式词库的 19 张表内容与两份媒体摘要保持一致，SQLite quick_check 为 ok；未替换为隔离测试词库。

真实受限制网络、听感和截图结果见[离线记录](../testing/restricted-network-results.md)。1002 条词库在后台导入/解释时读取 40 条的 P95 为 21.9 ms，最大 34.1 ms，可见 WebView 帧采样见[性能记录](../testing/performance-results.md)，不推广为所有负载保证。台式机正常重启与两次覆盖安装保持 14 表及原声摘要，见[台式机记录](../testing/desktop-machine-results.md)。保存中断和取消提交边界、真实同步另有对应记录。

这些结果为代码与交付的技术验收。实际学习体验、个人常用阅读器和正式词库连接由以下用户验收确认，不将测试夹具成绩当作用户学习成绩。

## 5 用户验收步骤

1. 安装本候选包，打开“观看前预习”，导入自己的 Modern Family 视频或目录；按词浏览并收录一个生词及原声。
2. 再收录同一词的新例句或释义，确认旧例句、原声与学习记录仍保留。
3. 在支持的阅读窗口选词，按 Ctrl+Alt+Shift+W；不支持时按 Ctrl+Alt+Shift+S 截图，修订后收录。
4. 在词库试听原声和系统声音，完成一题词义和一题听力；查看历史、下次复习及判分修正，确认自由浏览不算测验正确。
5. 查看易忘词原因和专项练习；本地解释在自己的 8096 服务可用时使用，失败后仍可手动学习。
6. 需要同步时在设置中允许按需联网，在浏览器登录原英语练习站点，核对设备名和连接码后批准；检查两端的例句、原声与学习记录。
7. 正常退出并重新打开，确认自己的保存内容仍在。主窗口关闭是隐藏到托盘，完全退出使用托盘菜单的“退出”。

记录实际问题时提供功能、输入类型、预期和实际结果；不要公开上传个人词库、影片或凭据。测试用的 1000 条合成词位于隔离目录，普通启动使用独立正式数据目录。
