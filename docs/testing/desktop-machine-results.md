## 1 环境与执行方式

工程位于台式机的 `C:\Projects\codex\SubtitleVocabularyList`，Windows 11 IoT Enterprise LTSC 26100、i3-12100、约 24 GB 内存。开发依赖见[环境说明](../development/windows-environment.md)，实际执行 Windows 自带 PowerShell 5.1。工程从公开 Git 仓库检出，继续使用 main 分支。

## 3 实际界面检查

恢复 RDP 会话后，附加到台式机实际 Tauri WebView2，页面使用随程序编译的 `http://tauri.localhost/` 资源。调试端口确认仅监听台式机回环地址，界面操作使用独立测试词库 `.tools\desktop-validation`。

- 快捷键状态显示划词与 OCR 均已注册，无注册错误。
- 页面实际加载，主窗口可见；页面视口 1220×780、DPR=2。
- 经真实确认窗口新建 reluctant，保存释义和自编原句，词库显示 1 次主动收录与 1 条例句。
- 实际点击系统英语朗读，播放器时间推进到 1.51424 秒并到达 ended，无媒体错误。该证据证明生成与解码播放，不证明实际扬声器听感。

## 4 前台取词与未完成项

创建同账号交互会话中的 WPF 只读测试窗口，程序能够设置 reluctant 选区。触发时 Windows 返回前台句柄和前台进程均为 0，虽然 WPF 报告自身 active=true；诊断显示窗口站与输入桌面为 WinSta0/Default。测试夹具因此拒绝发送快捷键，没有向未知窗口输入。

用户已协助登录 RDP 和点击测试窗口，本节早期远程测试不能确认真实全局取词成功，不能归因为已定位的软件缺陷，也不能把用户点击或注册成功记作完整取词验收。后续本地验证结果见第 5 节。[首台机器的真实取词证据](windows-capture-results.md)保持其原支持边界。

本轮尚未完成台式机截图 OCR 的实际选区与合并、真实视频进入桌面词库的完整流程、离线断网、安装升级和全面兼容验证。纯媒体探针成功与桌面端导入验收分开记录。M-06 至 M-08 仍需继续实施，不据新机器环境就绪宣称完整 0.1 完成。
