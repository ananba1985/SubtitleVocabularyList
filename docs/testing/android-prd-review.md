## 1 范围与结论

用户要求对照 PRD 检查并继续补齐，排除同步。本轮以 0.22.0 为起点，检查非同步 P0 的需求、手机入口、共享核心调用和既有验证证据；同步接入不作为本轮完成条件，P1 不扩入。

原有收录、合并、复习、播放和 OCR 主流程已经实现，但存在学习历史入口、中文查询与复制、可选模型配置、完整字幕偏移、缺译文补充、计时中断、图像清理和资源状态等细项缺口，另外发现多音轨原声缓存身份错误。以上在 0.23.0 补齐。当前未发现仍缺少实现入口的非同步 P0；这不等于全部设备、来源应用、服务或生命周期条件均已验收。

0.25.0 收尾核对：下表非同步 P0 沿用已通过证据；FR-14／15 的真实词库交换和 FR-22 的独立剧集共享现均已接入并有专项正常结果。目前 P0 实现清单无待开发项。自动同步功能已接入，本轮按用户设置保持关闭，未取得自动触发真机结果；可选真实远端模型、兼容矩阵及正式发行也不在已验证结论内。

## 4 维护方式

查询、词库合并、句子缓存、复习历史、字幕对齐、计时和原声缓存继续复用桌面 Rust 核心。Kotlin 只处理剪贴板、Media3、系统配置事件等 Android 接口，不复制业务数据库。偏移使用已索引 cue 生成应用私有 VTT，由原播放器渲染；音轨格式 ID 的稳定编号仅属于 Android 适配层。

具名合成素材与证据保留在忽略目录 `.local/android-acceptance`，手机原始素材在 `Download/SVL-Android`；测试只操作这些材料，不读取桌面正式 Data，不将手机资料、凭据、模型或媒体提交源码。
