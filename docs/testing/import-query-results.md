## 1 实现与测试环境

沿用 Windows 11 IoT Enterprise LTSC 26100、Tauri 2/WebView2、SQLite schema 5。原有词库和已批准的同步连接保留；本轮使用独立私有目录，未将真实影视、截图、词库或查询结果提交。核心和界面仍通过统一收录入口保存资料。

新增音轨与内嵌字幕选择、同名外置字幕及显式外置文件、强制本地转写。外置格式为 SRT/VTT/ASS/SSA，支持 UTF-8 与带 BOM 的 UTF-16；目录递归规则沿用原实现。音轨索引、字幕方式和实际外置内容参与缓存身份；更改选择建立独立预习资料，不覆盖旧来源或收录。资料标题说明音轨和字幕轨或外置文件；导入后再次核对视频与外置内容摘要，处理中发生变化时不将混合结果提交为成功来源。

自动模式依次检查同名外置字幕、英语内嵌文本、英语 PGS、英语本地转写；外置同名优先 `.en`、`.eng`，再无语言后缀，格式顺序 SRT/VTT/ASS/SSA。手动选择错误的轨道或外置文件时明确失败。字幕时间越界仍拒绝成功保存。

采集确认改为有序队列，快速到达的多个结果不会覆盖当前未保存草稿。关闭或保存当前草稿后，用户逐条打开或放弃队列中的结果。当前队列属于运行中确认状态，未提交草稿不承诺重启恢复；已成功原生任务仍保留既有任务记录。

## 3 发送范围与来源

查询只由明确按钮触发，传递当前查询文字，不附带收录例句、来源文件、截图、词库、原声或身份凭据。英语词典取 Wiktionary 的 English 部分，最多 120 个字符；中文翻译由 MyMemory 执行，最多 500 UTF-8 字节，结果标为机器翻译。原文过长时要求缩短，不自动截断。结果注明来源与地址，不执行返回的 HTML。

本机模型请求显式禁止代理和 HTTP 跳转，以保持回环服务边界；外部查询失败不改变已保存学习资料。HTML 读取使用 [scraper 官方接口](https://docs.rs/scraper/0.27.0/scraper/)，外部内容属于词典资料，不作为程序指令。

## 4 后续验收

最终 WebView2 界面实际选中音轨 2、字幕 4 后导入成功，来源列表显示独立资料和候选；界面截图已检查。更新后的在线中文翻译和英语词典按钮均得到成功任务与来源显示；未点击“采用”前手动释义保持不变，点击后只更新草稿，词库数量仍为 0。原文变化不会留下上一条在线结果；本地解释建议也在更改目标时清除。截图与任务详情仅保留私有验证目录。

本轮补齐导入选择、外置字幕、采集队列和查询实现；不同应用/屏幕支持矩阵、物理断网冷启动、安装/升级及完整同步故障边界继续执行。此记录不将合成事件当成实际跨进程采集，不把网络功能存在当成完整离线安装交付。
