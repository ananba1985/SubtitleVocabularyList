## 1 范围与环境

在本机 Windows 使用源码调试客户端、Qwen3.5-9B 回环服务和自编 WPF TextBox，验证选句、Ctrl+Alt+R、中文回填与原应用 Ctrl+Z 的一个正常流程。使用独立 `.local/replacement-acceptance` 词库，不操作日常词库、真实剧集或同步账号，没有生成安装包或发行 exe。

样本为 `Hi, Tom. I will arrive tomorrow. See you soon.`。桌面按键与撤销由用户实际执行，原生结果通过客户端 IPC 和 UIA 读回核对；浏览器工具只读取状态，没有代替真实跨应用按键。

## 3 首次失败与修正

初次真实操作没有替换，不记为通过。调试先暴露 UIA 初始化／重复焦点通知被当作用户改变目标，修正为核对实际焦点、文本和选区后再判定失效；随后实际模型已生成中文，截图对象格式阻止回填，改为保留可物化 DIB 并由 Windows 合成位图，不跳过无法保存的独立对象。

之后仍在粘贴前停止：原剪贴板序号在 Windows 关闭剪贴板、补全格式时增加，程序误将自身发布当作外部修改。改为关闭后取得发布序号并核对所有者；最后检查分别报告目标、按键、取消和剪贴板原因。最终原生读回进入 replaced，用户确认正常替换与撤销。

测试窗口另有 WPF 不支持 ClearUndo 的错误，导致 Prepare 提前中断。改为切换 IsUndoEnabled 清空夹具撤销栈，错误在窗口显示。夹具自动 JSON 的陈旧内容没有被用于证明成功；临时窗口和脚本在收尾时清理。

修正期间仅继续同一未通过的正常路径，没有执行额外故障注入、压力、权限、兼容矩阵或全套回归。

## 4 交付边界

首版面向同时提供 TextPattern、可编辑 ValuePattern 和连续选区的普通输入控件。没有验证浏览器富文本、密码／只读区域、管理员应用、多屏缩放、任意剪贴板对象、外部翻译服务或焦点竞争。异步 UIA 通知及 SendInput 不构成跨应用原子事务；这些边界的扩展验证须另行授权。

设置、缓存与写入方式见详细设计。功能在程序运行或常驻时可用，默认 Ctrl+Alt+R；本地设置可选择翻译服务、更改或禁用快捷键。失败可手动查看译文，不能恢复旧操作的自动写入。
