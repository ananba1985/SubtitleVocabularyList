以当前源码、实际构建、执行结果和界面证据为准。下表的“已验证”只覆盖列出的场景；“部分”不能作为完整通过，“待条件”保留尚未具备的网络或交互条件。历史增量记录保留原阶段，不因早期文档中的“未实现”忽略后来代码，也不因后来的局部成功关闭原必需范围。

当前发行候选的程序源码为 `047a48f`，安装器及源码材料已经实装和校验；当前 main 另包含验证文档。站点为版本 26，源码 `ed50f919859f78979a01cf61ce74cd1d8c371f11`，原公开访问范围和真实账号认证保持。

## 4 阶段与交付门槛

M-01 的范围与技术决策、M-03 的存储收录、M-04/M-05 的采集导入、M-06 的策略、M-07 的协议与真实交换均已有相应代码与证据；它们不能代替 M-08 的整体验收。

当前已有版本化安装器、匹配源码材料、组件条款、使用说明、旧库迁移与实际安装结果。恢复/性能探针是新增验证工具，不改发行程序的业务行为。正式发布说明与最终验收报告仍须在剩余条件完成后形成。

现有两项用户配合请求仍待实际回复：笔记本临时隔离测试程序外网需要管理员 UAC；台式机界面工具在无法确认 Edge URL 后终止，需要确认安全窗口状态才能继续。没有把预选项或等待时间视为批准。明确需要用户听辨/第二账号的条件保留，不伪造身份或听感。
