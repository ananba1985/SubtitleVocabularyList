## 2 实际打包与检查

直接执行根目录 `生成安装包.ps1 -SkipToolBuild`，复用已经准备的离线工具和模型。第一次在许可证收集阶段因 isarray@1.0.0 没有独立 LICENSE 文件退出；确认其 README 内有完整 MIT 许可，修正脚本收集规则。另修正产物选择，只匹配当前版本安装器，保留历史包。

使用修正后的同一脚本完整执行，返回 0。已收集 335 个锁定依赖的许可，前端类型／生产构建、Rust optimized 发行编译和 NSIS 生成均通过；六项工具／模型资源在构建前后摘要保持。源码材料按上述 Git 提交导出，临时源材料目录由脚本清理。

安装器和发行 exe 的版本为 0.6.1；安装器与源码 ZIP 的 SHA256 实际重算，与交付清单一致。源码清单提交号匹配，不打包本机词库、音频或凭据；本机用户数据位于已迁移的独立 Data 目录。仅新增打包流程维护及记录，按用户指定保持应用版本 0.6.1，没有创建发布标签或 GitHub Release。

## 3 本机安装步骤与资料

1. 从托盘完全退出调试或本地 exe。
2. 运行 0.6.1 x64 安装器，在目录页选择 `D:\SubtitleVocabularyList`。
3. 启动后在本地设置核对资料目录为 `D:\SubtitleVocabularyList\Data`，应能看到此前导入的 24 份剧集资料。

资料已经迁移，不需要再复制旧 `.local/dev-data`；备份位于 Data/backups。安装程序位置由用户选择，发行程序使用自身目录下的 Data。本机测试入口默认相同位置。直接运行交付目录内 standalone exe 时，使用的是 standalone/Data，不会自动使用本机安装目录的 Data。
