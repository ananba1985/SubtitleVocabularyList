SubtitleVocabularyList 是在 Windows 本机使用的英语学习工具与单词本。当前确认的观剧方向为“边看边学”：在软件内观看视频，遇到不懂的对白时暂停，优先读取字幕翻译、OCR 保底，按需收录后继续观看。观看前预习保留为可选流程；日常采集、原声、主动回忆测验和在线词库同步保持。新模块的内嵌播放、已保存译文与定时整句收录已接入开发版，其余能力和实际证据见[专项计划](../planning/watch-and-learn-plan.md)；0.1 基线与历史验收范围分别保留。

## 1 背景与问题

用户正在通过英语剧集提高英语水平，以 Modern Family 等本地剧集作为学习素材。最初采用观看前按词预习；经过实际使用，用户反馈每次看剧前先学习会打断兴趣，难以坚持。2026-10-21 确认改以观看过程中的即时理解为主要观剧流程：先看剧，不懂时暂停，再查看当前对白解释，真正需要记忆时才收录。原有预习不删除，也不作为观看前置条件。

收录后的复习需要判断用户能否主动想起含义、能否从对白中听出目标词。只阅读释义或点击已经记住，不能充分反映掌握情况。用户同时已有英语练习站点，希望桌面单词本能够与其在线词库连接。

已有单词本主要反映用户主动收录的内容，不能据此了解未收录的常用词掌握情况。用户于 2026-10-14 确认利用 Google 高频单词及常用组合进行可配置的水平摸底，识别不同词频段的薄弱项，并接入已有收录、复习和复测流程。

## 2 用户与产品目标

### 2.1 目标用户

0.1 面向在 Windows 本机学习英语的个人用户，使用本地剧集、阅读材料和已有英语练习站点。用户需要在无网络时完成主要学习流程，并在必要时使用联网查询与同步。

### 2.2 目标

| 编号 | 目标 |
| --- | --- |
| G-01 | 让用户先观看，不懂时暂停获得当前对白翻译和词义，再按需收录；观看前预习可独立选用 |
| G-02 | 在剧集和日常阅读中收录单词、短语和整句，保存语境与可用音频 |
| G-03 | 重复收录时累积例句、原声和重复学习记录 |
| G-04 | 通过测验区分词义理解与听力识别表现，并据此安排复习 |
| G-05 | 对反复遗忘的词进行专项练习 |
| G-06 | 离线完成核心功能，并与已有在线单词本同步 |
| G-07 | 通过高频词汇与短语抽样测试了解薄弱频段和能力维度，确认需要学习的内容，并观察后续变化 |

不预设未经验证的识别准确率、每日学习数量或语言能力提升指标。需要量化的性能和学习参数见待确认项；观看动线的调整不改写 0.1 历史验收事实。

## 3 版本范围

### 3.1 纳入 0.1

- 单个本地剧集文件或文件夹导入，取得可用字幕、对白和音频。
- 无可用文本字幕时的本地语音识别，以及识别结果纠错。
- 按单词和短语浏览候选内容，用户确认熟悉、收录或暂不确定。
- 全局划词与截图 OCR 采集，以及收录前确认。
- 单词、短语和整句收录，语境释义、来源、例句和原声保存。
- 重复词条合并，多例句、多音频和重复收录记录。
- 自由浏览与按计划测验复习，分别记录词义和听力表现。
- 易忘词专项。
- 本地翻译与解释，按需联网查询，无原声时的 Windows 本地英语语音兜底。
- 与已有英语练习站点的在线单词本同步。

### 3.2 后续再规划

高级每日负荷控制、批量熟词管理、复杂标签与统计、音频播放清单、完整备份与导出功能等不纳入本次 0.1 功能承诺。移动端、多用户协作和插件市场也不属于 0.1 基线范围；2026-10-22 启动的 Android 需求规划见第 3.9 节，不追溯扩展 0.1 验收范围。

### 3.3 产品边界

本产品独立运行，用户无需同时启动已有取词软件。对已有英语练习站点的扩展仅服务于词库集成。用户于 2026-10-10 授权将网站学习功能合入本地，新增 FR-13 听读练习；网站部署和账号访问规则继续保持，0.1 历史验收范围不自动扩展。

### 3.4 后续 Pot 替代增量

用户于 2026-10-11 确认后续需要独立翻译小窗、划词／OCR 自动翻译、剪贴板监听、多服务查询和插件扩展，本次要求先设计和规划，新增 FR-14 至 FR-18。用户随后授权执行本计划，首版在 0.5.0 接通，实际验收见 [Pot 替代验证](../testing/pot-replacement-results.md)；不追溯改变 0.1 的发布验收范围。功能设计见 [Pot 替代设计](../design/pot-replacement.md)，阶段见 [后续开发计划](../planning/pot-replacement-plan.md)。插件市场、完整 Pot 插件兼容和额外外部调用能力未据此直接承诺。

### 3.5 选区翻译并替换增量

用户于 2026-10-11 提出 FR-19，在其他应用选中输入的英文句子，按快捷键译为中文并替换原选区；设计提交后以“ok，please do”授权实施。0.6.0 首版实现见 [选区翻译并替换设计](../design/selection-replacement.md)，实际支持范围见 [增量验证](../testing/selection-replacement-results.md)，不改变 0.1 历史范围或既有查询行为。

### 3.6 高频词汇与短语水平测试增量

用户于 2026-10-14 确认新增 FR-20 至 FR-24，随后授权编写[详细设计](../design/vocabulary-assessment.md)和[开发计划](../planning/vocabulary-assessment-plan.md)。当前已按 M-15 至 M-19 接入 0.8.0 开发版，真实正常同步往返已通过；本轮听感已确认，用户决定本轮验收结束，未复核及题库覆盖边界见增量记录，不改变 0.1 历史验收范围。目标是“可配置范围的分层抽样测试 → 分频段报告 → 错词确认收录 → 学习后复测”。

首版需求包含快速摸底和指定范围测试，用户可选择 Top N、题数、单词／短语及题型；用词义辨识、语境填空和听音识义取得实际作答结果，分别报告词义辨识、语境回忆和听力表现。题库提前准备、离线可用，测试历史独立保存；学习收录仍需用户确认。

当前已接入的 Google 中文高频表主要提供单词，ECDICT 是释义补充来源，不能据此声称已有 Google 高频组合题库。组合需有可追溯的词频来源，筛选出自然、常用的固定搭配、短语动词或表达，经题目核对后才能纳入测试。已有数据不足时如实显示，不能用任意相邻单词拼成短语填充题库。

本模块报告选定题库范围内的抽样表现，不直接换算 CEFR、雅思、托福、四六级等等级或分数，不输出未经校准的精确词汇量，不宣称覆盖完整的听说读写能力。自适应难度、复杂心理测量模型、口语／作文评分、考试认证和排行榜不纳入本轮需求；具体默认参数、频段划分和题库校准见待确认项。

### 3.7 边看边学增量

用户于 2026-10-21 确认名称为“边看边学”，播放器内嵌于本软件；技术选型采用 mpv/libmpv，具体集成见[设计](../design/watch-and-learn.md)。新增 FR-25 至 FR-29，按[开发计划](../planning/watch-and-learn-plan.md)实施；已接入范围与未实现项分别记录，不因本地实现表示已经打包。

首版支持本地视频直接观看、基本播放控制、音轨和字幕选择、外置字幕、字幕延迟及全屏。用户暂停后自动在画面上显示当前句及导入视频时已生成、已保存在本地的译文，取不到原文时以当前帧字幕 OCR 保底。译文实际显示后仍持续暂停达到设定时长，自动收录当前整句；提前继续则不收录。用户确认默认时长为 5 秒，可修改或关闭，也可手动收录词、短语或整句。无需先完成全片候选或整集中文准备；直接打开未导入视频时，缺失译文须明确提示，可按需补充。

原预习、剧集导入、后台准备、单词本、听读、测验、水平测试、易忘词、划词／截图、翻译替换及同步继续使用。暂停自动收录仅适用于本模块的当前整句，不把全片导入或普通查询变为自动收录，也不标记掌握或产生测验成绩。新收录内容沿用既有学习规则。首版不承诺在线视频平台、DRM、自动整季学习、自动测验或替代所有通用播放器功能。

0.11.0 已接入当前文字字幕、独立流式查询及无文字时的帧 OCR 核对，0.12.0 接入音频互斥；后台正常结果和待人工步骤见[增量记录第 5 节](../testing/watch-and-learn-results.md#5-0110-后台开发增量)。新增窗口交互及声音切换尚待用户人工验收，在线字幕及发行资源继续实施，不据编译或单一核心样本宣称全部完成。

### 3.8 双语字幕取得与导入增量

用户补充要求：导入时提取内置字幕，并依据文件名称识别剧名和季集，必要时从已配置的互联网字幕服务取得英文、中文字幕，导入系统复用。新增 FR-30、FR-31，设计见[双语字幕导入](../design/subtitle-import.md)。0.10.0 已接入本地文本中英轨、同名外置字幕和当前句中文复用，正常证据见[字幕记录](../testing/subtitle-import-results.md)；0.13.0 在线取得、版本核对和人工偏移已接入，下载后数据正常流程通过，真实服务及新增窗口待验证；图片轨导出仍待实际样本。已有中文优先、模型仅补缺，原观看、收录与学习历史规则不变。

### 3.9 Android 客户端规划

用户于 2026-10-22 要求梳理现有产品功能、评估 Android 适用性并编写客户端 PRD，明确包含单词本、边看边学及与现有服务器同步。完整功能盘点、移动采集入口、数据同步范围和验收标准统一维护在 [Android 客户端 PRD](android-PRD.md)。用户随后认可该 PRD、复用设计及开发计划，并授权实施全部 P0；P1 保持后续候选。已接入共享宿主、Android 工程与手机单词本界面，阶段性结果见 [Android 验证记录](../testing/android-results.md)。两端独立运行，仅通过服务器同步个人资料；源码复用不产生手机对桌面进程或同网连接的依赖。Android 开发不改变 Windows 历史验收范围。

## 4 术语与业务概念

| 术语 | 定义 |
| --- | --- |
| 词条 | 用户收录的单词、短语或整句 |
| 候选项 | 从素材中整理出、等待用户判断的词或短语 |
| 例句 | 词条出现时的原始句子及对应语境释义 |
| 原声 | 来源素材中的真实对白音频，与系统生成语音分别标识 |
| 来源出现 | 某词在剧集或阅读素材中出现的记录，反映素材中的出现情况 |
| 主动重复收录 | 用户再次确认将已有词条加入单词本，反映重复学习或遗忘经历 |
| 熟悉 | 用户在当前语境下认为理解该候选内容 |
| 我已掌握（默认跳过） | 用户主动建立的本机全局筛选偏好；跨来源隐藏相同类型和词形，不产生测验成绩，可撤销 |
| 掌握状态 | 根据学习与测验记录维护的状态，不由是否已收录直接决定 |
| 易忘词 | 多次测验失败或反复主动收录，需要增加针对性练习的词条 |
| Top N | 指定词频来源及版本中排名不超过 N 的范围；单词与组合分别使用各自的排名，N 不等于已掌握数量 |
| 高频组合 | 有来源依据、整体含义和自然用法的常用搭配、短语动词或表达；不将所有相邻词序列视为合格短语 |
| 水平测试 | 对选定高频范围进行分层抽样，记录实际作答、维度和频段表现的诊断测试；与按计划复习独立 |
| 分层抽样 | 在所选范围内按预先说明的词频段抽题，各频段范围及实际题量可查看，避免只从最前面的熟词抽题 |
| 合格题目 | 有明确考查目标、适当语境、可核对答案及解释，题目所需资源可用，能在离线状态下完成作答与判分 |
| 边看边学 | 在本软件内先观看，暂停时理解当前对白，并由用户按需确认收录的观剧流程 |
| 暂停上下文 | 某次暂停对应的视频、位置、字幕轨、原文及文字来源；不同暂停不能混用解释或收录来源 |

## 5 主要用户流程

### 5.1 观看前预习（保留，可选）

1. 用户选择一个剧集文件或文件夹。
2. 系统取得对白与音频，整理按词浏览的候选列表。
3. 用户按单词或短语确认；需要时展开原句、释义并播放对白。
4. 用户收录需要学习的内容，系统保存例句、原声及来源；已存在的词条按合并规则处理。
5. 用户可在本次预习后观看剧集，也可直接通过“边看边学”观看，无需完成预习。

### 5.2 日常划词与 OCR 收录

1. 用户在其他应用中选中文字并触发取词，或截图选择需要识别的区域。
2. 系统显示取得的文字，用户核对目标词、例句和释义。
3. 无法自动取得完整上下文时，用户可补充；识别错误时，用户可修改。
4. 用户确认收录，系统执行与剧集收录一致的合并规则。

### 5.3 测验复习

1. 用户打开按计划安排的复习内容。
2. 系统出示词义回忆题或听力题，作答前隐藏答案。
3. 用户回答；系统记录正确、使用提示或错误，以及对应能力维度。
4. 系统据此更新复习安排；存在判分歧义时，用户可以纠正。
5. 多次失败或重复收录的词进入易忘词专项，按薄弱点继续练习。

### 5.4 在线词库同步

1. 用户在需要时连接已有英语练习站点。
2. 系统交换需要同步的词条内容，并按合并规则处理已有内容。
3. 同步成功后显示结果；网络、认证或服务异常时保留本地修改，用户可稍后重试。

### 5.5 写作中选句翻译并替换

1. 用户在原应用的可编辑输入框选中英文句子，按“翻译并替换”快捷键。
2. 系统使用本地翻译，保持原应用焦点；完成时核对选区仍为当前目标。
3. 直接用中文替换选中句子，未选内容保持；不自动发送、提交或保存。
4. 用户可以在原应用撤销。目标已经变化时系统不自动回填，仅提供译文供手动使用。

### 5.6 高频词汇与短语水平测试

1. 用户进入“水平测试”，选择快速摸底或指定范围；推荐设置可直接使用，范围、题数和题型可修改，非必要设置默认收起。
2. 系统显示本次词频来源、单词／组合范围、可用题量及维度；资源不足时先说明，用户调整配置或准备题库后再开始。
3. 系统在所选频段内抽取合格题目，作答前隐藏答案，按选择的题型完成测试；用户可以回答、标为不确定或选择不知道，也可暂停后继续。
4. 完成后展示各频段、单词／短语及能力维度的表现，列出答错、不确定和待确认内容；提前结束只形成明确标注的未完成结果。
5. 用户选择需要学习的词或短语，核对释义、例句及音频后确认收录，重复内容沿用现有合并规则。
6. 用户学习后再次测试，查看与历史可比测试的变化；不直接根据抽样结果把整个 Top N 标成已掌握。

### 5.7 边看边学（新的主要观剧流程，增量实施）

1. 用户进入“边看边学”，直接打开本地视频，或从已有剧集进入，开始正常观看。
2. 遇到不理解的对白时，在播放器中按 Space 或点击暂停；无需切换到其他取词软件。
3. 系统在画面上自动显示对应原句、位置及导入时保存在本地的译文；没有可读原文时使用 OCR 并允许纠错。缺译文时明确显示，可主动补充当前句，不因暂停反复请求模型。
4. 完整有效译文实际显示后开始倒计时，默认 5 秒；等待读取、OCR、模型回复或流式结果完整显示的时间不计入。
5. 5 秒内继续播放，取消本次自动收录；译文显示满 5 秒且仍在同一处暂停，自动将该英文整句、中文译文、来源及可用原声收入现有单词本，简短显示结果。用户可取消本次自动收录，或在设置修改时长、关闭此功能。
6. 用户仍可点词／选短语查询并手动确认收录；进入手动收录草稿后，本次暂停不再自动提交整句。
7. 继续播放时移除暂停译文和面板；已收录内容进入原有词库、复习和同步流程，以后可继续观看位置。重复暂停同一来源句不反复添加例句或累计主动重复收录次数。

## 6 功能需求与验收标准

FR-01 至 FR-12 属于 0.1 必需能力；FR-13 是 2026-10-10 授权的后续功能增量；FR-14 至 FR-18 是 2026-10-11 确认设计并授权实施的 Pot 替代增量；FR-19 是 0.6.0 授权实施的写作增量。FR-20 至 FR-24 是 2026-10-14 确认的高频水平测试需求，需求及设计计划已编制，代码已按 M-15 至 M-19 接入；真实正常往返通过，本轮听感通过，用户确认本轮验收结束，未复核项按增量记录保留。验收描述是验证依据，实际完成范围以增量记录为准。

FR-25 至 FR-29 是 2026-10-21 确认的“边看边学”增量，已开始核心闭环开发，执行状态见[验证记录](../testing/watch-and-learn-results.md)，不追溯扩展 0.1 验收范围。

### FR-01 剧集导入与对白准备

**需求**：系统应支持导入单个本地剧集文件或包含多个剧集的文件夹，取得对白文字、时间位置和音频。应优先利用可用文本字幕；无可用文本字幕时，应支持本地语音识别并允许用户纠错。

**验收标准**：

- 导入有可用字幕的素材后，能够浏览对应对白并播放关联音频。
- 导入无可用文本字幕的素材，在本地识别资源准备完成后能够生成可编辑的对白文字和时间位置。
- 文件夹中的剧集具有独立的处理结果；某个文件失败时，已完成内容仍可使用，失败原因可见。
- 图片型或不可读取的字幕不会被当成已成功提取的文本；系统提供可用的本地识别路径或说明处理失败。
- 已核对的 OCR 错字应纠正原句并重新整理候选，保留原始字幕、音频及已收录历史；带重音的拉丁字母不能被截成错误词片段。对刻意分音节的写法，只有合并拼写能可靠查到词义时才合并候选，不猜测改写原句。

### FR-02 按词确认生词

**需求**：系统应按单词和短语展示候选内容，在同一剧集内合并重复展示项。用户可标记熟悉、确认收录或暂不确定，并按需查看例句、语境释义和对白音频。

**验收标准**：

- 默认确认单位是单词或短语，用户无需逐句审核全部对白。
- 已导入资料可按剧名、季、集多级筛选，支持剧名、集名关键词搜索及自然编号排序；不同音轨/字幕版本保持可选择，无法分类的资料保留原名，不丢失旧收录和原声关联。
- 列表以英文和简短中文释义为主要内容；选中后读取已有语境解释或标明“通用释义”的词义，并独立显示原句译文。词义、译文已保存哪一项就先显示哪一项；次数等统计信息降为辅助查看，联网查询说明不占据默认学习区域。
- 同一词的多处出现可以从同一候选项查看，不丢失来源例句。
- 已收录但尚未掌握的内容仍可提示用户判断；已收录不等同于已掌握。
- 对当前语境的熟悉判断不会自动推断为理解该词所有其他含义。
- 用户可另行标记“我已掌握”，同类型、同词形的内容在本机已有和未来剧集默认隐藏；可显示已掌握内容、搜索管理并撤销标记，恢复无需重新导入。
- 标记不删除原句、原声或学习历史，不增加测验正确记录；再次明确收录后恢复展示并沿用原有复习优先规则。

### FR-03 划词采集

**需求**：系统应支持用户在其他应用中通过全局操作获取所选文字，并进入收录确认流程。自动获取上下文的范围应如实显示，允许用户补充例句。

**验收标准**：

- 在明确支持的应用中，触发取词能够显示本次选中文字。
- Chrome／Edge 首次启用选区接口尚未就绪时，应在同一次触发内短暂等待并重新读取，不要求用户重复按键；等待期间原窗口变化则停止，不使用旧选区或剪贴板替代。
- 浏览器当前焦点控件返回空选区时，不能据此直接认定网页没有选中文字；应核对原前台窗口内当前可见网页文档的实际选区，排除隐藏页面，保留密码字段和窗口变化检查。
- 默认划词和截图快捷键沿用本机 Pot 的使用习惯，提供可保存的输入翻译／收录快捷键；允许用户自定义或留空禁用。同键被其他应用占用时明确提示，不把未注册状态显示成可用。
- 获取失败、未选中文字或取消时，不会自动收录旧内容。
- 用户可以核对或修改内容后再收录；支持应用清单在实现验证后确定。
- 所选目标已标记“我已掌握”时，默认跳过收录窗口，保留“仍要查看”的显式入口；未知目标继续原确认流程。

### FR-04 截图 OCR 采集

**需求**：系统应支持选择屏幕区域并在本地识别文字，识别结果可编辑，并进入统一收录流程。

**验收标准**：

- 网络断开且本地识别资源准备完成时，截图识别仍可运行。
- 截图快捷键应尽快显示可操作的本次选区，不在框选前等待文字识别或翻译；准备临时快照应以响应速度为先，保留原始像素清晰度。
- 用户可以修改识别文字或取消操作。
- 识别目标完整内容及类型命中“我已掌握”时默认跳过确认窗口，可主动查看；句子中出现熟词不会删除原句中的文字。
- 截图、裁剪或识别失败不会使用上次截图的结果完成本次收录。
- 在声明支持的屏幕缩放和多显示器场景中，识别区域与用户选择区域一致。

### FR-05 单词短语与整句收录

**需求**：系统应支持收录单词、短语和整句，保存原文、语境释义、例句、可取得的来源和音频。应保留自动识别或解释内容的人工纠错能力。

**验收标准**：

- 三种内容类型均可收录、重新打开并浏览。
- 例句中的词义与该次来源关联，新的语境不会覆盖旧释义。
- 用户明确将同一例句关联到新的释义或解释时，各条已确认语境均保留，复用原句与已有原声，不因关联新增而复制媒体。
- 不存在完整来源或音频的内容仍可收录，缺失情况如实显示。
- 用户纠正后的内容在重新启动应用后仍然保留。

### FR-06 重复收录与合并

**需求**：系统应支持将已有词条再次收录，追加新的例句、释义和音频，保留旧内容和学习历史。应区分来源出现与用户主动重复收录。

**验收标准**：

- 同一词条从新的对白再次收录后，能够同时浏览旧例句与新例句。
- 相同来源片段重复加入时，不产生重复例句或重复音频副本。
- 用户新的主动重复收录可增加相应记录；自动导入重试和同步重试不会冒充一次主动收录。
- 再次收录不会清空测验历史；已掌握的词再次收录后，应重新提高复习优先级。
- 可能对应不同含义或不同内容类型的条目，不进行不可纠正的盲目合并。

### FR-07 原声保存与本地语音兜底

**需求**：有来源音频时，系统应保存与收录例句对应的原声，供日后复习。没有原声时，应能使用 Windows 本地英语语音朗读词条或例句，并标明音频类型。

**验收标准**：

- 剧集收录完成后，即使原剧集文件被移动或删除，已保存对白仍可播放。
- 原声播放内容与所示例句对应，用户可以识别字幕或截取位置需要纠正的情况。
- 无原声且已安装本地英语语音时，断网仍能朗读。
- 原声和系统生成语音具有明确标识，不把生成语音标记为来源对白。

### FR-08 本地解释与按需联网查询

**需求**：系统应接入用户已有的本地大模型服务，生成语境释义与例句解释；用户需要时可进行联网查询。

**验收标准**：

- 外网断开、本地服务可用时，能够取得语境释义和解释。
- 本地服务不可用时，用户仍能浏览和复习已有内容，并收录原文后补充释义。
- 自动生成内容可人工修订。
- 软件、项目、品牌等专名允许保留原拼写，并展示模型提供的中文解释；模型把中文解释放在说明字段时，应整理字段而非将整份结果判为空白。查询结果不合约定时，应说明具体原因并展示模型原始返回供核对，不能据字段校验失败推断输入有拼写或 OCR 错误。
- 系统支持独立离线基础词库。优先复用已保存解释，再按 Google 高频词表、ECDICT 顺序查询；词库有有效中文释义时直接显示，支持明确的词形还原，两库均未命中才由本地 AI 补充。后台排队和手动词语查询遵循同一规则；底库内容不自动加入个人生词本或复习计划。通用词典释义与语境释义区分，整句翻译独立补缺。
- 查词支持弯／直撇号和经核对的书写变体，缺失的基本缩写可使用注明来源的中文补充。匹配不改写原词、原句或掌握状态；不能通过一律删除 `’s`、猜测 `’d` 展开或自动纠正疑似 OCR 来提高覆盖数。有歧义的内容保留语境判断。
- 安装包携带 Google 高频词库及 ECDICT，首次安装即放入用户所选安装目录下的 `Data/dictionaries`，无需首次启动联网下载。升级替换随包基础词库，保留个人词库、已保存解释、例句和学习记录；打包不得读取或携带开发机的个人数据库。
- 用户可通过全局输入入口打开文字输入窗口，按需解释、朗读或确认收录；查看翻译不强制保存成词条。
- 导入成功后后台按规范化词／短语准备一次通用中文释义与用法，跨集复用；对白译文按完整原句独立去重，不为每个“词×对白”组合提前生成释义。已有资料启动后补齐，离开预习页不停止。特殊语境释义由用户明确请求，旧结果保留。任务分别显示词义与句子译文进度，不为每项成功新增历史。
- 预习界面直接读取已保存的本地解释，不因打开页面或滚动而请求模型。缺失内容如实显示后台准备状态，可优先准备当前集；模型失败保留已完成结果，支持恢复，不自动改用外网。切词、换语境或纠正原句后，旧结果不覆盖当前内容。
- 已生成的词义、原句译文和用法说明重启后仍保留；更换模型或模型不可用时直接显示已有资料，只有缺失内容需要生成。
- 后台中文准备遇到临时连接失败、超时或服务繁忙时，在原任务中等待并自动重试，服务恢复后继续，等待状态及重试入口可见；等待期间可取消，不重复生成已保存资料，不为每次重试新增历史。无效解释有限补试，仍无效则保留未完成原因并继续其他项目。历史失败记录表示当次执行结果，不作为模型当前可用性判断。
- 英文缩写展开式及“无此单词／请检查拼写”不能冒充有效中文释义；旧自动缓存中的此类诊断不作为准备完成依据，得到有效结果后可修复该缓存，个人词义及学习记录保持。罕见候选可参考原始大小写及相邻字幕判断专名、口语或外语，仍按词去重保存，不重新展开所有“词×对白”组合。不因未知专名而编造身份、词源或发音。
- 唱出的字母序列应保留正确字母，并用中文说明其内容，不因没有可逐字直译的中文单词而永久无法准备。
- 用户可手动配置同时进行的本地模型请求数量，默认串行，配置在本地保存。后台准备与手动解释遵守同一上限，保存后作用于运行中的准备任务；调低上限不打断已开始的请求。多个结果仍按目标与语境保存，聚合进度保持一致，不形成逐词成功任务历史。实际生成速度取决于模型服务的并行能力。
- 用户可配置后台每次请求最多处理的词条或句子数，保存后重开仍保留；通用词义和整句译文各自合批，不足时按实际数量请求。配置作用于待执行项目，不打断在途请求或改写已有结果。
- 联网查询由用户操作或明确启用的设置触发；失败时不丢失当前收录内容。
- 默认允许联网；连接失败时自动继续离线使用本地功能，重试成功后恢复在线状态。保留明确的手动离线选择，不将临时失败保存成禁止联网的设置；登录失效、限流或服务错误单独提示。

- 基础词库资源读取异常时，应明确提示不可用的资源；其他健康词库、已保存的词条、原声和基础复习继续可用。修复资源后可重新打开程序恢复使用。

### FR-09 自由浏览与复习

**需求**：系统应支持按词浏览已收录内容，自由查看多条释义与例句，并播放对应音频。自由浏览与按计划测验同时保留。

**验收标准**：

- 用户可选择词条查看其已有例句和音频。
- 自由浏览不要求先完成测验，也不会仅因看过答案就自动记录为测验正确或已经掌握。
- 同一词条的原声和释义具有清晰的对应关系。

### FR-10 测验与复习安排

**需求**：系统应通过主动回忆测验评估掌握情况，支持词义回忆和原声听力相关题型，并分别记录词义理解与听力识别表现，根据结果安排后续复习。

**验收标准**：

- 作答前隐藏相应答案；听力题在需要时隐藏字幕，播放对应音频。
- 正确、使用提示和错误得到不同记录，错误或需要提示的内容较早再次复习。
- 多次间隔测验通过后可延长复习间隔；不能仅靠自由阅读延长间隔。
- 含义相近且符合语境的回答可被接受；用户可修正有歧义的判分。
- 词义与听力表现分别保留，避免一次词义题正确掩盖听力困难。
- 测验和复习安排在离线条件下可执行，不强制依赖在线服务或可用的大模型。

### FR-11 易忘词专项

**需求**：系统应根据多次测验失败和主动重复收录识别易忘词，区分词义、听力或短语使用等薄弱点，提供针对性解释和练习。

**验收标准**：

- 满足专项规则的词条能够进入专项列表，用户可查看进入原因。
- 某词多次词义回忆失败时，能够增加词义相关练习；听力薄弱时能够使用对应音频练习。
- 再次练习保留原来的例句和测验历史。
- 本地大模型可辅助解释，但其不可用不会阻止基础专项练习。
- 触发与退出规则在实施前明确并记录，具体阈值不由本文臆定。

### FR-12 在线单词本同步

**需求**：系统应与用户已有英语练习站点的在线单词本双向同步词条、释义、例句、原声音频和学习记录，使桌面新收录与学习内容可同步到站点，并将在线已有内容合并到本地。完整同步范围已经用户明确确认。

**验收标准**：

- 在真实站点连接与认证成功后，可完成本地新增到在线、在线新增到本地的完整流程。
- 重复同步不会产生重复词条、重复例句或重复主动收录计数；已在当前账号确认保存的版本无需再次获取完整资料。新增例句、原声、作答或修正后，仍能在另一端恢复完整资料。
- 已有确认基准且两端支持时，新增作答或修正只交换变化内容，上传和下载均复用未变化的例句、题目和旧历史；接收端按同账号、同实体的确认基准恢复完整资料，经校验和持久化后再确认成功、推进同步进度。首次同步、缺少基准或旧端仍能沿用完整同步，不截断原记录。
- 离线修改可保留，恢复连接后能够继续同步。
- 认证失败、网络中断或服务异常时，本地词库和学习功能仍可使用。
- 两端存在冲突修改时，不静默覆盖用户内容；具体处理规则进入同步设计。
- 词条、释义、多例句、原声和学习记录均须在两端保留正确关联；实际接口字段、认证与版本规则在同步设计中明确，不能因现有站点字段不足缩减已确认范围。

### FR-13 本地听读与逐句输入练习

**需求**：将已有英语练习网站的阅读与课程学习流程合入独立的本地入口，支持离线导入、听读、逐句输入和连续听读，并复用既有词库收录、解释、查询与复习功能。

**验收标准**：

- 可粘贴英语文本，导入 UTF-8 TXT、未加密 EPUB 2/3 和现有 `.lesson.zip` 课程包；EPUB 按阅读顺序分章，课程保留原句和音频时间位置。
- 听读界面按本地窗口组织：960×640 逻辑视口内直接呈现播放、原句、输入、反馈和句子导航；600×420 最小逻辑视口仍可阅读当前原句并输入。目录、播放设置、解释查询按需打开，原句与输入随可用高度分配空间，长内容在区域内滚动。
- 可选择章节或句子，重听当前句、选择本地英语声音和慢速／舒缓／正常速度；有课程原声时可选择原声或 Windows 本地语音。
- 输入区域即时显示正确和错误文字，可展开逐字比对查看剩余文字；忽略大小写，统一全角、弯引号和空白，保留标点判断。正确后自动进入下一句并朗读，跨章继续，结尾停止并提供单词本入口。
- 连续听读随播放切换并突出当前句。原声从当前句连续播放，重叠时间不重复播放；“停止”留在当前句，“结束并返回”及自然播放到结尾恢复开始位置与输入草稿。
- 当前阅读、章节、句子、草稿、速度与声音在本机保存，离开页面或重新打开后可继续。课程原声在导入时复制到应用数据目录，无需重新打开原课程包；新阅读替换当前练习，已收录词条、例句、原声和学习历史保持。
- 选择原句中的词语可进行本地解释和统一收录；无选词时可解释、收录整句。课程收录可保存对应原声片段，阅读来源可追溯，重复收录沿用 FR-06。
- 核心练习无需登录或联网；联网查询仍由明确按钮触发。完整阅读、练习草稿、速度和声音偏好不随词库同步，收录后的词条例句、原声和学习记录沿用 FR-12。逐句抄写不冒充主动回忆测验成绩。

- 更新输入草稿和练习位置时只保存进度，不重复保存完整正文。已有合并记录在升级后仍可继续阅读，保留正文、位置、草稿、速度、声音及原声关联。

### FR-14 独立翻译小窗

**需求**：用户可通过独立的小窗查询单词、短语或句子，不必打开主窗口，也不必先决定收录。

**验收标准**：

- 小窗直接展示原文与查询结果，支持输入后查询、复制译文和朗读；可通过关闭或 Esc 隐藏，不退出常驻应用。
- 手动输入、划词、截图及剪贴板查询默认自动识别中英方向：英文译中文，中文译英文。英文词语查询中文释义，英文句子／段落完整翻译；中文词语和句子均返回英文译文，不能返回中文释义代替英译。不能仅提取段落中的一个词冒充整段结果。保留手动选择英文词义解释或整段翻译，以便纠正自动判断；中文输入即使选择英文词义解释也按英译处理。翻译不复用词义解释缓存，也不清除已有资料。
- 窗口适合屏幕可用区域，主要内容直接可见；服务与附加选项按需展开。
- 查询不增加词条、主动收录、测验或同步记录；只有明确收录时才进入既有确认与合并流程。
- 原有未保存收录草稿不被新查询覆盖；已有有效解释在重开或服务不可用时可读取。
- 本地模型查词与整段翻译逐步显示已生成的文字，区分排队、等待回复和正在生成；不必等完整答复才看到内容。命中底库或已有资料时直接显示结果。
- 生成中的文字仅供预览；完整答复通过校验后才允许复制、收录和保存查询缓存。取消或修改输入后，旧查询的后续片段不能覆盖当前输入。流式展示改善等待体验，不承诺缩短模型计算时间。

### FR-15 划词与截图自动翻译

**需求**：完成取词或截图识别后，系统在翻译小窗自动展示当前文字的解释或译文，减少手动点击。

**验收标准**：

- 沿用用户已设置的三组快捷键；读取本次选区或截屏前不打开小窗遮挡原应用。
- 划词保留可取得的完整语境；仅取得选中文字本身时按无原句查词，正常展示中文词义，不因缺少额外句子译文而失败。截图原文可核对和纠错；取消或失败不使用旧内容发起查询。
- 自动查询默认本地服务；外部自动服务必须由用户明确启用，发送范围可知，本地失败不静默改用外网。
- 切词或修改输入后只展示相应结果，旧响应不覆盖新词；沿用全局已掌握跳过规则，明确手动查询仍可查看熟词。

### FR-16 剪贴板监听翻译

**需求**：用户主动开启监听后，复制的新纯文本可直接进入查询小窗；用户可随时关闭并查看真实状态。

**验收标准**：

- 监听默认关闭且重启后关闭；不开启时不读取、查询复制文字，开启时说明所选服务和缓存行为。
- 只处理开启后的新文本，连续复制合并到最新输入，相同内容不重复请求；复制本程序译文不产生查询回环。
- 小窗和托盘显示监听状态；关闭监听停止新查询并取消相应待发／在途查询，不影响其他手动查询。
- 监听不自动加入生词本或同步复制内容；用户可配置监听结果是否持久保存为查询缓存，缓存与词库保持区分。

### FR-17 多服务查询

**需求**：用户可配置多个翻译或词典服务，设置默认、顺序和自动查询范围，对比结果后自行选择使用。

**验收标准**：

- 复用已有本地模型和在线查询服务，能保存服务的启用、顺序及调用范围；离线核心功能保持。
- 各服务结果分别展示，先完成先显示，一个服务失败不清空其他有效结果。
- 结果和缓存标记实际服务来源；选择某个结果后再进入收录，不静默覆盖已确认释义。
- 外部自动查询默认关闭，手动离线禁止全部外网请求；服务只接收用户允许的文字或语境，不发送截图、词库和学习历史。

### FR-18 插件扩展

**需求**：用户可通过可管理的插件扩展服务，按已声明能力安装、配置、启用、禁用和卸载。

**验收标准**：

- 首批支持翻译和词典插件，安装时可查看版本、能力和服务地址；不支持的版本或能力明确提示。
- 插件的结果遵守与内置服务相同的展示、取消、缓存和明确收录规则。
- 禁用／卸载后停止新调用，已保存词条、例句、原声和学习记录保持，原结果来源可追溯。
- 现有 Pot 插件的直接兼容须另行评估，不把安装成功等同于完整兼容；具体包格式和执行方式见设计文档。

### FR-19 选区翻译并替换

**需求**：用户在其他应用中写好英文，选中句子并按专用快捷键，可自动译成简体中文并替换原选区，减少复制、切窗和手动粘贴。

**验收标准**：

- 提供独立可保存、可修改或禁用的快捷键，不改变已有划词、截图和输入查询入口；注册冲突明确提示。
- 在支持的可编辑输入框中取得当前非空连续选区，默认用本地模型翻译；正常过程保持原应用焦点，不要求再次确认或打开主窗口。
- 只替换选中英文，未选内容保持；不发送消息、提交表单、保存文档或用全选覆盖整个输入框。
- 回填前核对同一窗口、控件、选区位置和原文；用户改变目标、取消或翻译未取得有效结果时不自动写入；已有译文可手动查看和复制。
- 支持原应用的标准撤销路径，具体撤销粒度及编辑器支持范围以实际样本为准；无法确认可编辑状态的内容不自动替换。
- 本地翻译失败不静默转用外网；明确选择外部服务时沿用联网规则。自身回填不得触发剪贴板监听查询回环，剪贴板处理与恢复边界可知。
- 不自动收录生词、增加学习成绩或发起同步，不把轻量写作操作逐项记录成后台任务历史；不将事件发送成功冒充已确认替换成功。

### FR-20 水平测试配置与范围

**需求**：用户可针对常用单词和短语发起快速摸底或指定范围测试，自行决定测试范围、题量和内容，不必先将目标词收录到个人单词本。

**验收标准**：

- 提供“快速摸底”和“指定范围测试”两种入口。快速摸底采用可查看、可修改的推荐设置；高级设置按需展开，不在默认页面堆叠题库管理、来源明细或所有历史记录。
- 支持 Top 1000、Top 3000、Top 5000 等预设，以及自定义正整数 N；N 受所选词频来源的实际范围约束。界面明确 Top N 是来源排名范围，不是英语等级、题目数量或掌握数量。
- 用户可配置题目数量、单词／短语／混合内容，以及词义辨识、语境填空、听音识义的选择。单词与短语排名分别说明；混合测试能查看两类的实际范围和题量，不将两份排名混为一份。
- 开始前显示本次所选范围、题型及实际可用题量。未准备好的题目不计为可用；无法满足配置时说明缺项，让用户调整或准备，不能静默缩小范围、重复凑题或把开始测试变成等待模型逐题生成。
- 在所选范围内按词频段抽样，提供频段和题量说明；单次测试控制同一目标及明确屈折词形的重复，不将重复出现当作多个独立词汇掌握证据。
- 水平摸底不能因个人词库已有收录、全局“我已掌握”或预习默认隐藏偏好而排除熟词，避免只测生词改变样本范围；不改动上述偏好本身。
- 有效配置在本机保存，重新打开可复用；题库版本或可用范围变化时先提示实际变化，再确认开始，不沿用已经无效的范围而不说明。

### FR-21 高频测试题库与题目质量

**需求**：系统以有来源依据的高频资料建立可离线使用的题库，提前准备并核对题目，让评分依据稳定、组合用法真实。

**验收标准**：

- 词频范围记录实际来源、版本和排名口径，词条数与可测试题目数分别显示；ECDICT 可辅助释义，不能以其全部词条充当 Google Top N。题库准备不自动导入个人词库。
- 组合题目只采用经筛选的自然搭配、短语动词或常用表达，记录整体含义与用法，不能把各词的中文拼接成组合含义，也不能仅因相邻词出现频繁就视为合格短语。单词、组合的质量及覆盖状态分别可知。
- 每题有明确目标、题干、必要语境、可接受答案及解释。词义辨识有可区分且合理的选项；语境填空答案符合整句，允许合理变体，不能把词典中的一条简译机械地设为唯一正确答案。
- `the`、`of`、`to` 等依赖语境的高频词通过句子考查含义或用法，不用脱离语境的单一中文释义判定是否掌握；多义词说明本题考查的含义，一题正确不等于其所有义项均已掌握。
- 本地模型可用于提前辅助准备题目、解释和答案，但生成内容经核对后才成为可评分题目；无有效答案、歧义未解决或资源不完整的题目不进入正式测试。核对和版本维护方式进入后续设计。
- 题干、答案、解释及所需音频提前保存，题库准备进度集中在后台任务页，不在其他学习页面重复展示；题库或模型暂不可用时，已准备内容仍可测试。
- 已开始测试使用稳定的题目及评分版本，后续题库更新不改写其题目、作答和历史结果；同一题出现质量争议时可标记并复核，不能把错误题目造成的失分默认为用户不掌握。

### FR-22 水平测试作答与判分

**需求**：通过实际作答分别观察用户的词义辨识、语境回忆和听力表现，保留不确定、提示及判分状态，完整测试无需联网或在线模型。

**验收标准**：

- 支持词义辨识、语境填空、听音识义；辨识题与需要主动回忆的题分别记录，不把选择题正确一概视为能够主动使用。
- 作答前隐藏答案及解释；听音题不提前展示会泄露目标的英文或完整字幕。确认作答后按测试流程提供讲评，不泄露尚未作答题目的答案。
- 用户可提交答案、标记不确定或明确选择“不知道／想不起来”；正确、错误、不知道、不确定、使用提示及待确认状态能够区分。猜中或使用提示不冒充无提示、确定的正确回忆。
- 合理重听与正常答题可执行。存在原声时保留来源，无原声可使用明确标识的 Windows 本地英语语音；播放失败或资源缺失时不记录为听力错误，允许重新准备、跳过并说明未计分。
- 判分接受预先核对的合理答案变体；离线无法自动确定的回答列为待确认，允许查看依据、修正或标记题目问题，不因字符串不同直接判错，也不强制等待模型判分。
- 测试中不隐式发起外部查询或同步。已准备的题目在断网、本地模型不可用时仍能作答、判分并保存；用户另行主动联网的行为沿用已有联网规则。
- 保存本次配置、实际题目、答案、提示／不确定状态、评分及修正依据。暂停、重开后可继续同一测试，已提交作答不重复记录；提前结束保留已有结果并标明未完成，不冒充完成全范围测试。

### FR-23 分频段报告、历史与复测

**需求**：用户可查看本次高频测试的薄弱频段和维度，并比较后续可比测试的变化，了解需要继续学习的内容。

**验收标准**：

- 报告首先呈现所选范围、完成状态、有效作答量和各频段表现；单词／短语、词义辨识／语境回忆／听力分别统计，不能只用一个总分掩盖差异。题目明细、来源和完整历史按需展开，历史分页查看。
- 各频段显示实际题数、可计分题数及结果；明确正确率的分子和分母。不知道和有效错误不能被排除以抬高成绩，未播放、无效题和待确认项单独说明，不伪装为已答正确或用户错误。
- 抽样结果使用“本次已测表现”等明确表述，样本不足的频段显示不足，不把未测词判为已知或未知。未经校准不按“正确率 × Top N”声称精确词汇量，也不直接换算语言等级或其他考试成绩。
- 用户可查看答错、不确定、使用提示及待确认的具体内容，并查看答案、语境和解释。判分修正或题目复核后重新计算相关报告，保留修正记录。
- 历史记录在本机持久保存，退出重开仍可查看。重复测试保留每次结果，不覆盖旧报告；比较时同时说明范围、题型、题量和题库版本差异，条件不一致时不声称同尺度提升。
- 同一会话的报告按业务内容区分；仅同步修订号、生成时间或本机媒体定位变化时复用已有报告。原有报告（包括已有重复版本）全部保留；作答、判分修正、题目依据或收录关联改变报告内容时保存新版本，原回答和旧报告继续可追溯。
- 复测仍按选定频段抽样，尽量减少短时间重复原题造成的答案记忆；题库有限或存在重复时如实说明，不能靠重复同题制造进步结论。
- 水平测试历史作为独立类型的学习记录，沿用 FR-12 完整同步目标；后续同步设计需明确新增资料的交换与站点支持，不能只同步总分或把本地保存宣称为已完成两端同步。

### FR-24 水平测试结果确认收录

**需求**：用户可从测试结果中确认需要学习的词和短语，沿用现有收录、合并和复习流程，形成摸底、学习、复测的闭环。

**验收标准**：

- 结果页集中展示答错、不确定等待巩固内容，支持选择一个或多个目标，预览目标、释义、例句及可用音频后确认收录；可取消，不把所有错误自动加入词库。
- 未收录内容按 FR-05 保存，已有内容按 FR-06 合并，保留既有人工解释、例句、原声和学习历史，不因测试结果覆盖。重复点击或同一保存重试不产生重复词条或重复收录计数。
- 题目例句可作为明确标识的测试来源保存，不能伪称来自某一剧集；真实原声和系统语音分别标注，未取得真实原声时不伪造对白录音。
- 测试会话与平时复习记录分开。答题或生成报告本身不改变现有到期安排、易忘词状态或全局“我已掌握”标记，也不因频段成绩较高而把整个 Top N 批量隐藏。
- 用户确认收录后，新增或已有词条按现有规则进入学习与复习；所确认的重复收录保留原有优先规则。收录后的词条、例句、音频和学习记录继续遵守 FR-12，不缩减已有同步范围。
- 从报告进入收录或复习后能返回原报告；日后复测保留原测试与对应学习内容的来源关联，报告不会因某个词已收录而丢失。

### FR-25 内嵌播放器与直接观看

**需求**：提供“边看边学”入口，在本软件内播放本地视频，以观看为主体，不要求先预习或完成全片导入准备。

**验收标准**：

- 打开视频后能在应用内播放、暂停、定位、调音量、切换音轨／字幕、加载外置字幕、调整字幕延迟和全屏；不要求另启外部播放器。
- 停止播放不能只依赖快捷键：普通窗口有可点击的“停止播放”，全屏浮动控制条有停止按钮，视频右键菜单也提供停止。停止关闭当前视频、取消尚未完成的本次学习计时并退出全屏，保留播放列表和观看进度，不退出软件。
- 基础播放优先复用成熟播放器的完整原生能力，播放音视频不等待词库、翻译或学习处理完成；保持原视频分辨率，不以降低画质或帧率作为卡顿处理。具体实现及同源素材证据在设计、验证记录中明确。
- 打开、选集或自动连播切换视频时，当前剧集名称和收录来源跟随实际播放文件更新，不保留上一集的信息。尚未完整导入的视频自动在后台导入字幕和剧集资料，播放不等待导入；已有完整资料直接复用，同一视频的进行中导入不重复启动。完成后更新对应剧集，不能重载视频、改变播放位置或把旧视频结果绑定到新视频。导入失败在后台任务保留原因，当前视频仍可播放，完整导入不等于自动把全片加入个人单词本。
- 新视频打开后自动检查当前目录的同剧文件；依据文件名中的剧名及集号聚合，发现其他待导入集时提示是否导入同目录完整剧集，说明数量并允许查看文件名。确认后在后台批量导入其余集，当前视频继续播放；选择仅当前集则不导入其他视频。同一观看页面内已选择的同目录同剧不反复提示。已完整导入的资料跳过，不递归扫描子目录，不能把同目录文件数量当作网上完整集数。
- 播放期间主要空间用于画面和基本控制，查询、导入和高级设置不默认堆在观看区；暂停时才展开本次学习内容。全屏时隐藏侧栏、页面标题及打开工具栏，视频占满屏幕，不保留底部白色面板；播放控制随鼠标移动浮现、停止操作后隐藏，Esc 可退出。
- Space 在播放器焦点下切换播放／暂停。通过软件按钮进入全屏时，自动将键盘焦点交给视频；全屏时即使焦点留在软件按钮或软件窗口内其他非编辑区域，Space 也切换播放／暂停，无需先点击画面，一次按键只切换一次。在编辑框内仍能正常输入，不改变原全局采集快捷键。
- 支持保存观看位置及播放选择；用户主动打开剧集、选择列表中的视频或点击继续观看后，恢复该文件的进度并直接播放，无需再点播放。软件启动不自行开播；切页或最小化暂停，仅返回页面不擅自播放。具体已支持媒体范围以实施后的实际记录为准。

### FR-26 暂停后优先取得当前字幕

**需求**：用户观看中主动暂停后，优先取得当前视频、字幕轨和时间对应的对白，不依赖屏幕取词或人工复制。

**验收标准**：

- 有可读文本字幕时优先直接取得原文，包括内封或用户加载的外置字幕；已有同源可靠对白可按时间复用，不因标题相同使用其他视频／字幕版本的句子。
- 原文与时间位置可核对，字幕轨或延迟变化后对应更新。使用最近一句时明确标识“上一句”，不能把不相关对白当作当前字幕。
- 缓冲、拖动、切页等内部暂停不自动发起学习查询；同次用户暂停不因重复通知反复查询。
- 查询期间继续播放、跳转、换轨或换文件后，旧结果不会覆盖新的暂停内容；原文缺失时明确说明并提供保底路径。

### FR-27 暂停对白翻译与按词查询

**需求**：暂停时自动在画面显示与当前原句对应、在导入视频时已生成并保存的中文译文；允许按需补充缺失译文及查看单词／短语解释，不阻碍继续观看。

**验收标准**：

- 按同一视频、字幕版本及对白位置读取已有整句译文，暂停后自动显示，无需再点查询；不重新生成、覆盖已保存的有效译文，也不把通用词义当整句翻译。
- 没有译文时明确提示“暂无已保存译文”，允许用户补充当前句；手动补充复用本地模型流式显示，完整有效结果保存后可复用。未导入视频仍能直接观看，不要求先完成全片准备。
- 译文靠近当前原字幕显示，跟随原字幕在底部、顶部或人物附近的位置；不统一固定到底部。边缘空间不足时调整到原字幕另一侧，避免盖住原字幕；缩放与全屏后重新定位。
- 自动收录计时从完整有效译文实际显示之后开始；读取、OCR 和模型等待均不算，首个流式字符、请求完成但尚未显示或隐藏页面也不能提前开始计时。
- 点词或选短语可以查看中文词义及当前对白语境，沿用底库优先和模型补充规则；通用词义与整句翻译分别呈现。
- 不因暂停自动生成整集候选或启动整季资料准备，不重复请求已保存的有效结果；交互查询遵守已有并发配置。
- 模型异常时保留原文、明确原因并可重试；播放和已有词库仍可使用。不能把查询失败描述为字幕不存在，也不自动发送给外部翻译服务。

### FR-28 当前帧 OCR 保底

**需求**：没有可用字幕文字而画面有字幕时，识别暂停帧中的字幕作为翻译原文，并允许用户核对纠错。

**验收标准**：

- 图片字幕、硬字幕等无法直接取字时使用当前视频帧字幕区域，不截取无关桌面内容，不要求再次切到全局截屏窗口。
- 展示 OCR 来源，可重新框选、编辑原文并重查；字幕文字已取得但模型失败时不改走 OCR 掩盖查询原因。
- 没有可识别字幕时可手动输入、加载字幕或继续观看，不自动启动整片转写。
- OCR 帧位置与可靠对白起止时间分别标识，不把单帧识别伪装成精确字幕时间；临时图像遵守既有资料目录和回收规则。

### FR-29 暂停定时收录、手动收录与原有功能共存

**需求**：在“边看边学”中，完整译文显示后持续暂停达到设定时长，自动收录当前整句；快速继续播放则不收录。手动选择词、短语或整句仍按确认流程执行，两条路径复用现有词库、合并、原声及学习规则。

**验收标准**：

- 自动收录默认开启，用户确认初始时长为 **5 秒**；可关闭或设置正数秒数。仅在用户主动暂停且完整有效译文实际显示后开始倒计时，等待翻译的时间不计入，计时不能从按下暂停或模型请求开始。未满设定时长就继续播放，不收录；达到时长且仍是同一暂停语句时，自动收录该**整句**及其中文译文，不自动拆词入库。
- 画面上有紧凑倒计时及“本次不收录”，保存后简短显示“已自动收录”；不弹出强制确认框、不打断继续观看，也不把日常每次暂停写成后台任务历史。
- 继续播放、跳转、换文件／轨道、离开页面、隐藏窗口、修改原文／译文或取消本次时使原计时失效；内部暂停、初次加载与回到已暂停页面不自动启动。进入手动收录草稿后取消本次自动提交，避免两条路径重复操作。
- 缺少原文、没有完整有效译文、当前来源不明确或 OCR 原文尚未核对时不自动入库，明确原因并保留补充／手动收录入口；必要资料补齐并显示后重新开始完整计时，不追算等待时间。
- 同一来源、字幕版本和对白片段的自动保存可持久去重，重复倒计时或重新暂停不会重复添加，也不冒充新的主动重复学习；不同例句及用户手动再次收录仍按原规则保留。
- 手动收录前可核对目标、中文解释、原句、视频／字幕来源、位置和可用原声，确认才保存。普通查询、播放、短暂停顿和取消均不产生收录；所有观看行为都不产生测验通过记录。
- 有可靠字幕边界时可保存对应原声；仅有 OCR 帧位置时由用户调整、试听片段或只存文字，不伪造精确对白原声。手动选定区间只作用于本次手动收录，自动收录仍按原采集位置只存文字。已确认原声保存后不依赖视频原路径。
- 新词保存、已有词追加例句及重复主动收录沿用 FR-05 至 FR-07；保留旧释义、原声和学习记录，同一保存重试不重复计数，完整同步范围遵守 FR-12。
- 预习、导入、后台任务、听读、测验、水平测试、易忘词、全局采集及翻译替换原入口与记录保持；播放器不覆盖其他学习会话，不同时叠加本应用的学习音频。
- 观看位置独立于掌握／复习状态保存，观看不自动标熟；不建立平行词库、不更换默认资料路径、不要求迁移用户现有数据才能使用。

### FR-30 导入时取得中英字幕

**需求**：剧集导入应先探测内置及同名本地字幕，尽量取得英文和中文；缺失时依据文件名中的剧名、年份、季集，从用户配置并授权的在线字幕服务补查。

**验收标准**：

- 分别保留两种语言和原字幕版本，双语轨可识别；不因已有英文而跳过中文字幕探测，不改写原字幕显示位置。
- 检索前可核对剧名、季集；候选须核对同一剧集及发行／时间版本，名称不明确或存在多个候选时由用户选择，不静默采用第一个结果。
- 无网络、服务未配置或未找到字幕时仍可完成本地可用部分并观看，明确缺失语言和原因，保留后续补充入口。
- 在线访问遵守原用户授权和集成配置，仅传检索所需信息，不上传视频或个人词库；资产与缓存在当前 Data 内持久化。

### FR-31 双语字幕对齐及暂停译文复用

**需求**：将同源中英字幕按时间关联，已有可靠中文字幕优先供边看边学读取，仅为缺失内容补充翻译。

**验收标准**：

- 按时间对应当前英文句，允许两种语言分句不同；不能按字幕行号直接拼接，不匹配剪辑版的中文不得当作当前句译文。
- 保留原字幕、时间和出处，区分下载／内置字幕、模型译文与用户修正；已核对中文可直接显示，且不再次调用模型。
- 补充中文字幕不重建个人词条，不更改既有来源／例句关联和学习记录，不造成暂停自动收录重复。
- 导入字幕本身不收录整集；仍从完整译文实际显示后计时，默认 5 秒，提前播放取消。
- 可为当前中文字幕设置固定时间偏移，保存后按新时间读取，原字幕、既有句译文和个人学习资料保持。

### FR-32 播放列表与自动连播

用户可一次选择多个本地视频，或添加一个目录中的视频，按文件名自然顺序组成播放列表；未导入的视频同样可观看。列表默认收起，可查看当前集、点击切集、上一集／下一集、调整顺序、移除或清空。重复添加同一路径不新增重复项。自动连播默认开启，可关闭；开启时片尾顺序进入下一集，最后一集停在结尾，关闭时每集结尾暂停。

**验收标准**：正常两集列表可从第一集片尾进入第二集；换集同步切换字幕及学习来源，清除上一句的查询、OCR 和未到期收录计时，不将换集或片尾内部暂停算作学习暂停。播放列表只表示观看顺序，不自动导入候选词或收录整集。

### FR-33 可视化倍速与播放偏好保存

播放器提供可见倍速选择，默认 1×，可选 0.5／0.75／1／1.25／1.5／1.75／2／3／4×。原生倍速快捷键继续生效，当前实际倍速同步到选择框，改变时在画面短暂提示。倍速、音量、静音和自动连播开关自动保存；列表及当前集保存。每个视频独立保存播放位置、音轨、主／第二字幕及字幕延迟，恢复仍可访问的已手动加载字幕。

**验收标准**：正常修改后重开资料库可读回偏好及列表；重新打开某视频恢复它自己的进度和轨道，已到片尾的文件从头开始。切换字幕或调整延迟后立即换集，仍保存并恢复最近选择，不回退到较早快照。重启软件只恢复列表数据，不自行播放；主动点击继续上次列表或选择视频后，加载并直接播放。数据存于所选 Data 的本地资料库，不改动个人词库、学习记录和既有导入；不新增 AppData 播放配置。

### FR-34 鼠标操作与紧凑播放菜单

播放器支持滚轮调音量、水平滚轮定位、鼠标侧键切集及原生左键／双击行为。右键或菜单键可打开播放设置，窗口和全屏共用同一菜单；工具条只增加一个“播放设置”入口，不平铺新增功能按钮。

**验收标准**：菜单覆盖播放／暂停、停止播放、剧集、倍速、声音、字幕、定位、循环和全屏；按当前状态显示勾选。停止与暂停明确区分，停止关闭当前视频但保留列表和进度。菜单、时间输入和字幕文件选择期间取消尚未到期的自动收录；选择菜单项时核对当前视频，旧视频菜单不操作新视频。

播放时提供明确的“播放器设置”入口，普通窗口可直接点击，全屏可通过浮动控制条的齿轮打开。复用已有倍速、声音／音轨、字幕显示／字号／位置／延迟、循环与连播设置，不要求用户编辑配置文件；已保存参数按原规则恢复，音轨和字幕延迟仍按文件保存。

### FR-35 音轨与字幕播放控制

菜单可选择或关闭音轨、主字幕和第二字幕，分别控制两路字幕显示，调整字幕提前／延后、字号和位置，并加载外置字幕。样式与显示偏好保存，轨道及延迟继续按视频保存。已有字幕文件的原定位和样式按播放器支持处理，不为修改位置强制破坏原 ASS 排版。

首次观看或未手动选轨的视频，有英文字幕时默认选择英文主字幕；字幕语言与音轨同为英语也应显示，不依赖容器默认字幕标记或操作系统语言。明确手动选择的其他字幕／关闭状态按当前文件恢复，全局字幕显示开关仍沿用用户偏好。自动未选中字幕不能被保存为用户明确关闭。

**验收标准**：正常双字幕视频可独立选择两路字幕，修改后快照反映实际选轨和样式；暂停时切轨／调整后刷新当前句，旧查询和倒计时失效。加载或切换字幕保留原播放／暂停状态，程序显示的状态与实际播放一致。通过菜单或原有加载入口选择字幕均走同一控制路径；选文件期间切换视频时不把旧选择应用到新视频。重开可读取已保存偏好。

### FR-36 定位、章节与循环

菜单提供指定时间定位（秒、分:秒、时:分:秒）、前后 10 秒、上一句／下一句／重播当前句和章节列表。定位保持原播放／暂停意图，主动暂停定位后刷新当前对白。单集循环、列表循环可选择并保存，当前模式可见；A–B 可设置起点、终点并清除。

**验收标准**：正常视频能定位到指定时间与已有章节；A–B 从 B 回到 A。列表循环开启自动连播；关闭自动连播时退出列表循环，仍可单集循环。显式选择循环模式清除 A–B；A–B 不跨集、不写入长期偏好。旧时间输入在换集后失效；恢复进度的内部定位不触发学习暂停或自动收录。

### FR-37 拖放与文件打开

主窗口及视频画面接收本地视频、视频目录和外置字幕。视频／目录按自然顺序加入已有播放列表并去重，已有当前视频时只加入列表，不切集或改变播放／暂停状态；没有当前视频时打开首项并直接播放。目录只加入本层视频，拖入目录不会触发整季导入或翻译。字幕直接加载到当前视频；同批视频和字幕在目标视频加载完成后应用字幕，首份为主字幕、第二份为第二字幕，其余加入可选轨。

资源管理器“打开方式”可选择本程序打开视频；冷启动与程序已运行均切到边看边学，保留原列表并选择传入视频，加载后直接播放。安装器只登记可选打开程序，不修改用户已有默认播放器。窗口沿用既有紧凑布局，不增加常驻拖放按钮。

**验收标准**：普通文件及含空格的路径能打开；目录内 Episode2 排在 Episode10 前；同一路径不重复加入。视频画面可直接接收字幕，当前字幕和已保存逐文件字幕记录更新。视频加载期间连续收到的字幕请求按接收顺序保留并绑定同一目标，主／第二字幕不因后一请求覆盖而丢失。字幕不误加入视频列表，未开视频时给出先打开视频的提示。换集使待加载字幕的旧目标失效。冷启动／再次调用程序的文件参数都能到达播放器，配置用的资料目录参数不作为视频。个人词库、例句、原声及学习记录沿用原保存规则。

### FR-38 同账号共享已准备剧集资料

**需求**：桌面已准备的剧集字幕、原文／译文、时间／偏移、视频指纹和准备版本通过既有服务器供同账号 Android 下载复用；设备独立运行，不要求直接连接或同网，不自动上传视频文件。

**验收标准**：电脑退出后手机仍可下载资料，匹配手机本地同版视频并显示对应译文；版本可追溯，既有词条、例句、原声和学习历史保持。新增能力尚未实施，用户已安排先开发其他离线功能，后续再做真实同步验证。对应 AND-FR-22、AND-AC-12。

## 7 数据与业务规则

| 编号 | 规则 |

| BR-01 | 已收录、当前语境熟悉、自评已掌握的筛选偏好、根据测验掌握，是不同概念 |
| BR-02 | 一个词条可有多个例句、语境释义和音频；再次收录以累积内容为目的 |
| BR-03 | 来源出现次数与主动重复收录次数分别统计 |
| BR-04 | 相同内容的任务重试、同步重试与用户明确再次收录，应能够区分 |

| BR-06 | 原声与生成语音分别标识，例句与音频保持对应 |
| BR-07 | 复习状态按测验维度维护，判分修正保留记录并反映在后续安排中 |
| BR-08 | 联网查询和同步属于可选连接；本地使用不要求在线登录 |
| BR-09 | 高频测试的单词排名、组合排名、合格题量、实际作答量与已掌握数量是不同口径；报告保留来源及题库版本，不混称英语等级 |
| BR-10 | 水平测试记录与计划复习分别维护；抽样通过不推断未测内容已掌握，测验本身不改变个人收录、到期、易忘或全局隐藏状态 |
| BR-11 | 只有用户确认的测试结果收录进入原有合并及学习流程；历史测试不因底库、题库或个人词条更新而被静默改写 |
| BR-12 | 观看、暂停、查询和收录分别处理；边看边学允许译文显示满设定时长后自动收录当前整句，其他手动收录仍需确认；两者共用原合并流程，观看位置不等于掌握或测验成绩 |
| BR-13 | 暂停学习保留视频、轨道、位置和文字来源；文本字幕、已有对白和 OCR 的来源及时间精度不得混称 |
| BR-14 | 暂停定时收录默认 5 秒，从完整有效译文实际显示起计时；等待不计、提前播放取消、同一来源对白自动保存去重，不把自动触发冒充主动重复收录 |

| 编号 | 需求 | 验收依据 |
| --- | --- | --- |
| NFR-01 | 核心流程离线可用 | 本地资源准备完成后，在无外网环境完成导入、OCR、收录、播放和基础测验；大模型扩展按本地服务可用性执行 |
| NFR-02 | 数据保存与关联完整 | 已确认保存的词条、例句、原声和学习记录，以及已生成的中文词义、译文和用法说明，在正常重启后可用；已有解释不依赖模型在线或浏览器缓存，模型只补充缺失资料；中断和重试不制造错误关联或重复操作 |
| NFR-03 | 后台任务可观察且不阻断主要操作 | 导入、识别、收录、连接和同步等后台任务可跟踪并取消；日常播放、朗读、听力音频准备和本地解释在当前功能内反馈，正常完成或取消不形成任务历史，失败可查。后台任务页显示全部需要跟踪的未结束任务，主区仅最近一条终态，历史默认折叠并分页；旧版本日常成功记录不占列表和页数。其他页面不重复展示全局后台进度，导入提交提示仅在导入页显示。对象、时间、结果和失败原因可见，已保存资料仍可浏览 |
| NFR-04 | 依赖故障可独立处理 | 独立基础词库、本地模型、联网查询或同步异常，不阻止已有词库浏览、音频播放及基础复习；基础词库异常须可见，健康资源继续可用 |
| NFR-05 | 本地资料按需联网 | 剧集、截图、原声和个人词库不在本地处理过程中自动发送到外部服务；联网查询与同步的数据范围明确 |
| NFR-06 | 资料与缓存位置明确 | 安装位置由用户选择，业务资料和应用缓存位于安装目录的 Data 子目录；本机调试与本地 exe 默认共用用户指定的 D:\SubtitleVocabularyList\Data，不必每次传参数。现有资料迁移保留记录和音频关联；不以 AppData 作为独立的默认资料库或缓存位置 |

兼容的 Windows 版本、文件格式、屏幕配置和可接受的处理耗时，在技术验证后形成明确的测试矩阵。本文不将未验证的全平台或全应用兼容写成承诺。

NFR-03 的状态更新补充：任务变化及时反映到当前功能和任务页，已结束记录仍按原规则展示；空闲窗口不持续定时查询任务。重新显示窗口时核对当前状态，未结束任务长时间无更新时可补查；隐藏窗口暂停定时补查。

NFR-02、NFR-03 的同步增长补充：可释放已确认或已明确处理完毕的重复传输副本，保留必要回执信息、未确认请求和完整业务历史。同步状态读取不反复重建未变化的全部学习资料；资料发生变化后重新核对，不以减少传输或缓存状态为由截断例句、原声、作答、修正或旧报告。

服务端应复用已经校验并保存的变化内容，减少再次同步时对完整历史的重复读取、比较和存储；历史的保存形式可优化，但仍须完整还原例句、原声关联、作答、修正和旧报告，不因生成新检查点而删除旧版本。实际数据布局及还原范围进入数据和同步设计。

NFR-03 的交互等待补充：数据库操作等待后台工作完成时，窗口仍应处理交互；同步冻结多个词条的过程在词条之间允许其他本地操作继续，不以后台执行宣称具体延迟达标。

NFR-03 的本地同步诊断补充：支持显式启用轻量操作耗时、数据库互斥等待及持有时间统计，不记录词条、答案、账号、凭据或媒体路径。按采样定位重复构建与数据库占用，复用仍有效的完整资料，并将可分离的计算移出持锁区间；提交前核对资料版本，不因减少计算而省略完整历史或改变冻结请求、回执及后续变更的保存规则。单次采样不作为固定延迟或整机性能保证。

同一要求的验收补充：可重建的同步索引与摘要集中保存，避免为未变化的映射单独提交写事务；已有完整确认且未变化的本地资料不重复构建比较。回执期间若存在后续本地变化，仍须保留为待同步资料；真实新报告和完整接收保存继续按业务事务提交。验证同时记录完整处理次数、提交范围与本地操作总耗时，不能仅凭某个阶段缩短判定整体改善。

接收合并完成完整校验、实体映射及原有字段合并后，最终保存值未变化的业务行应跳过更新，避免触发无意义的变更标记；新行、实际变更和必要修订仍须保存。减少写入不能省略不可变学习事件核对、原声核对或复习历史重算，也不能因 JSON 排版差异重写词条学习事件中语义相同的原题目／收录回执。

同步状态准备需要生成新报告时，报告与其派生状态应一起保存，避免同一次准备分开提交；操作成功后，报告和同步状态须对应同一份完整资料。已改变或未完成保存的准备结果不得发布为当前状态，原冻结请求、回执及后续变化的保存规则保持，已有报告和完整学习历史不得改写或删除。

会话因作答、修正或同步状态变化而重建完整资料时，应复用仍有效的未变题目和已有报告处理结果；新增、已变化内容及整包关联仍须核对。复用必须区分账号、会话和实际内容／引用变化，不因缓存截断完整例句、原声、作答、修正或旧报告，也不要求保留每个历史会话的多份完整副本。

同步派生传输对象应与持久历史区分，按账号和有界批次回收过期、可重建的技术缓存。旧混合对象须先核对当前及全部历史引用，有引用时先完整迁移保存再移除旧副本；不得按年龄删除仍被历史依赖的内容。无法确认的永久对象保留，原声、完整业务资料、冻结的待提交内容及所有历史版本保持可用。缓存回收不代表无限容量或已经降低真实账号的总存储。

NFR-03 的容量可见性补充：同步超限应提示实际大小与本次能力上限，并保留完整本地资料；差量较小不能绕过完整资料的容量约束。提供不修改业务资料的既有快照／冻结请求及持久原声大小诊断，明确未冻结变化不在采样范围。不能以删除历史、截断内容或未达到上限宣称无限容量；后续是否采用历史分页根据实际增长证据另行设计。

NFR-03 的窗口与启动验收补充：初始窗口适合当前屏幕可用空间，窗口模式与最大化有明显区别；小窗口和显示缩放下可通过滚动完整访问页底操作及侧栏信息。启动页面加载期间提供明确提示，页面加载失败可重试。关闭主窗口默认完全退出，用户可选择保存为常驻托盘；完全退出停止后台处理并释放快捷键，托盘模式保持处理与采集入口。关闭未提交的收录草稿不产生收录行为。托盘左键恢复当前主窗口，右键显示常用功能菜单；菜单可进入词库、预习、听读、测验、易忘词、同步、任务和设置，直接发起手动收录、截图收录或展开剧集导入。完全退出始终结束进程，不受常驻设置影响。

启动性能需以主界面实际可用为依据，加载提示不能代替延迟修复。验收分别记录开发编译准备、已编译程序启动以及首次界面就绪的耗时，明确缓存与参考硬件条件；具体实测见[性能记录](../testing/performance-results.md)。

NFR-03 的开机启动配置补充：本地设置提供独立开关，默认不主动登记；读取当前 Windows 用户的实际启动登记，开启／关闭立即生效，失败明确提示而不假报成功。开启后登录 Windows 自动运行当前程序并使用开启时的资料目录，正常显示主窗口；关闭开关不退出当前程序。开机启动与关闭到托盘独立，完全退出不取消下次登录启动。此项属于当前电脑／用户的配置，不随词库迁移或同步，不更改词库、例句、原声和学习历史。

## 9 外部依赖与约束

- 用户提供合法可用的本地学习素材。
- “边看边学”需要应用内嵌播放组件及离线资源；具体构建、许可与已支持媒体范围由设计和后续验证记录明确，不依赖已安装的 PotPlayer。
- 本地识别和语音资源需要在离线使用前准备完成。
- 本地解释能力使用用户已有大模型服务，具体接入配置由架构文档定义。
- 在线同步依赖现有英语练习站点提供桌面可用的认证和数据接口，需要对站点进行必要扩展。
- 来源音频的可用性影响听力题；无原声时可以使用已标识的系统语音。
- 高频水平测试依赖可追溯的词频资料和合格题库；已有中文词典可辅助释义，不能替代题目质量核对。组合频次、自然用法和有效题量须独立准备，不能据已有单词底库宣称组合测试已就绪。

## 11 0.1 整体验收

0.1 发布时，应有执行证据表明本节场景和第 6、8 节的验收标准已满足，失败项与限制如实列出。

| 场景 | 验收结果 | 关联需求 |
| --- | --- | --- |
| 导入一集有字幕剧集并完成预习 | 按词确认，收录生词与原声，重新启动后可以复习 | FR-01、FR-02、FR-05、FR-07 |
| 本地处理无可用文本字幕的素材 | 取得可纠正的对白与时间位置，并完成收录 | FR-01、NFR-01 |
| 从阅读应用划词以及截图收录 | 本次文字正确进入确认流程，取消与失败不误收旧内容 | FR-03、FR-04、FR-05 |
| 再次遇到已收录词 | 累积新例句与音频，保留历史，区分重复收录与重试 | FR-06、FR-07 |
| 完成词义与听力测验 | 两类结果独立记录并影响后续复习，可修正歧义判分 | FR-09、FR-10 |
| 对易忘词进行专项练习 | 原因可见，练习针对薄弱点，历史持续保留 | FR-11 |
| 与已有站点交换词条 | 两个方向均在真实账号下完成，重试不重复，本地异常隔离有效 | FR-12、NFR-04 |
| 无外网使用 | 核心流程可用，联网功能失败不破坏已有内容 | NFR-01、NFR-02、NFR-04、NFR-05 |
