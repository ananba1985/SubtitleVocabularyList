## 1 评估依据与整合结论

用户授权评估并将已有网站功能合入本地。评估依据为本机 `D:\Projects\codex\english-practice` 的 README、`dist/index.html`、`dist/app.js` 和同步字段契约，以及本项目当前实现。网站访问工具本轮无法读取线上页面，因此源码核对不冒充当前线上功能验收。

| 网站能力 | 本地现状与本次处理 |
| --- | --- |
| 粘贴、TXT、EPUB、`.lesson.zip` 阅读导入 | 新增独立“听读练习”，本机解析、章节与句子导航；不调用另一项目的处理脚本 |
| 当前句听读、速度和英语声音选择 | 复用 Windows SAPI，本地生成 WAV；课程可选择原声或本地声音 |
| 输入即时反馈、正确后自动换句与朗读 | 新增逐字符反馈、规范化比对、跨章前进及结尾词库入口 |
| Watching mode 连续播放、跟随、停止／返回 | 新增连续听读；课程使用同一音轨推进，系统语音逐句播放，保留开始草稿 |
| 浏览器练习位置保存 | 改为 SQLite 保存阅读和位置；课程原声复制到本机，重开不需重选原 ZIP |
| 选词释义、整句翻译与生词收录 | 本地解释和显式联网查询复用既有命令；统一收录和片段保存，核心流程离线使用 |
| 账号词库、多例句、原声、历史和纠错 | 已有本地模块继续使用；练习入口复用原确认窗口，不建立另一套词库 |
| 桌面账号连接与词库同步 | 继续既有契约；`reading` 来源为既有开放文本字段。完整阅读、草稿、速度与声音不进入词库资料包 |

未加入语音录音、发音评分、统计平台或新的网络服务。网站登录仍只服务站点账号词库，本地练习无需登录。逐句抄写不会写成回忆测验正确记录。

## 2 实现边界

前端新增 `practice.ts` 和 `PracticeView.tsx`，原生新增 `practice.rs` 及五个练习命令。JSZip 3.10.1 随本项目安装和构建，选择 MIT 许可，既有发行许可和源码收集脚本会按依赖图收集其传递依赖。此轮未执行打包。

SQLite schema 继续为 6，`settings.practice` 保存完整阅读和本机位置，位置更新只发送六个练习字段。来源、例句、确认收录、原声、复习和同步沿用现有业务规则。新的阅读替换当前练习，旧完整音轨可清理，已保存独立片段保持。

EPUB 仅提取可读文字，不执行书籍 HTML；加密书、PDF、Kindle 格式和扫描书不属于此入口。原课程的字幕与时间质量仍由课程包决定，人工解释和纠错入口保持。

## 3 最低必要验证与实际结果

使用 Windows 本机开发环境与独立 `.local/practice-validation-0.4.0` 数据目录，启动入口为 `pnpm desktop:dev`。并发开发触发自动重启后，使用同一开发配置的 `tauri dev --no-watch` 完成余下核对。验证中的本机程序版本为 0.3.3／0.3.4，功能作为后续 minor 版本交付；没有生成发行目录或安装包。

| 检查 | 实际结果 |
| --- | --- |
| TypeScript 与前端生产资源构建 | `pnpm build` 通过，JSZip 随前端本机资源编译 |
| 原生存储与统一收录 | 一个针对本次功能的通过路径测试：阅读、原声文件、速度与草稿保存，重新打开数据库，例句来源与统一词库收录保持；1 项通过 |
| 真正原生开发程序 | Tauri 编译、启动和 WebView2 加载成功；使用真实 IPC，不注入词库接口模拟 |
| 四种输入 | 实际粘贴、UTF-8 TXT、包含两章的 EPUB 和带 AAC 音轨的课程 ZIP 均导入成功 |
| 最终 EPUB 解析 | 章节按 XHTML 解析并仅提取正文；最终前端模块在独立浏览器中正常解析一份带 XHTML 命名空间的 EPUB，章节标题和两句正文一致。此解析检查不作为原生命令证据 |
| 输入与 SAPI | 大小写不敏感的正确输入后自动换句，输入框清空；第二句 SAPI WAV 实际生成并播放，播放器时间前进；EPUB 第一章结束后进入第二章 |
| 连续原声 | 使用 10 秒合成音轨、三句含重叠时间的课程；0.85 倍播放随时间进入第二句，“结束听读并返回”恢复第一句和原草稿；再次播放后“停止”留在当前句，草稿按当前位置清空 |
| 自然结尾与恢复 | 从第二句连续播放至结束，恢复第二句及 `I can` 草稿；页面重新加载和程序重启后仍为第二句、0.85 倍、同一本机原声音轨 |
| 选词、保存与片段 | 在原句实际双击选中 `practice`，通过原确认窗口保存“练习”、来源和对应原声；词库中有一条例句，时间 2500–6000 ms，独立原声长 3500 ms、状态 ready，实际播放时间前进 |
| 界面和诊断 | 已查看本机当前窗口截图，原句、选择、蓝色输入和灰色待输入文字可见；本轮 WebView2 控制台错误／警告为 0 |
