本计划定义 0.1 及后续增量的验证层次、环境、场景和验收证据。TC-01 至 TC-42 为既有基线，TC-43 至 TC-47 为 Pot 替代增量，首轮证据见 [Pot 记录](pot-replacement-results.md)。TC-48 为 0.6.0 选区翻译替换，执行及修正见 [替换记录](selection-replacement-results.md)。预期结果不能作为通过报告，文档检查不能代替功能测试。

## 1 验证层次

| 层次 | 验证对象 | 适用方法 |
| --- | --- | --- |
| 核心规则 | 内容匹配、重试、追加、判分修正、复习维度 | 小规模自动化测试，使用确定输入与数据库结果 |
| 本地集成 | 数据库与媒体提交、模型、转写、OCR、语音 | 真实工具或资源测试，并覆盖失败注入与取消 |
| 桌面流程 | 全局触发、焦点、选区、多屏、预习与测验交互 | 在声明支持的 Windows 环境中操作并检查实际输出 |
| 站点集成 | 认证、字段映射、双向交换、回执与冲突 | 契约测试后使用真实站点账号验证完整流程 |
| 整体验收 | 离线使用、重启保存、资源与异常隔离 | 按 PRD 场景串联执行，核对音频和数据实际可用 |

不为低影响界面文字或简单转发函数编写只重复实现的测试。优先验证可能造成错误收录、数据丢失、误判掌握和同步覆盖的行为。

## 2 环境与测试资料

| 维度 | 需要记录或准备 |
| --- | --- |
| 应用 | 提交标识、构建版本、安装方式与架构配置 |
| 系统 | Windows 版本、CPU、内存、显示器、各屏缩放与坐标布局 |
| 本地资源 | OCR 与转写引擎、模型版本、英语语音、媒体工具和运行时 |
| 网络 | 外网可用、外网断开但本机回环可用、本地模型停止、站点认证失效 |
| 素材 | 有文本字幕、无文本字幕、图片字幕、多音轨、坏文件、时间重叠及缺失片段 |
| 业务数据 | 单词、短语、整句、同词多含义、多来源例句、已掌握与易忘词记录 |
| 站点 | 实际地址、账号范围、接口版本和已确认同步字段；凭据不进入仓库 |

公开测试资料使用自行编写的文本、合成或自录的短音频及可公开的小视频。用户的真实剧集用于本机验证时，记录素材标识与必要结果，不提交剧集或个人词库。

支持矩阵在原型后确定。候选环境未测时标记未验证，不能写成已兼容。无字幕和 OCR 的离线测试应使用新的输入，避免只证明缓存结果可读。

TC-07/39 的快捷键对齐补充：正常升级样本中，旧工厂划词／截图值转换成 Alt+C／Alt+E，新增 Alt+D 输入键，保存和重开保持；仅执行该核心路径及必要桌面编译／前端类型检查。真实全局触发需要先退出占用相同快捷键的 Pot；未执行的触发不记作通过，不扩展为额外占用、兼容或故障矩阵。

TC-39 的托盘交互补充：最小正常检查为左键恢复主窗口、右键展示分组常用功能菜单，点击后台任务进入对应页面。Windows 桌面编译和前端类型检查通过后，以用户实际点击确认记录该路径；不额外执行全菜单功能、截图识别或复习回归。

TC-39 的跨页展示补充：导入运行时切换到词库、测验、专项、同步及设置，不出现主区进度摘要或导入成功提示；导入确认只在导入区域。提交后立即离开该页面，晚到的响应也不产生跨页提示。返回后台任务页仍可查看完整进度、取消和历史，后台处理不因页面切换而中断。

TC-39 的历史降噪补充：连续播放、朗读、准备听力音频和解释正常成功或取消，不增加 tasks 数据库记录，不挤掉最近同步或导入。预置旧版成功临时记录，分页列表与总数排除这些记录。失败仍持久化可重开查询；临时操作可查询结果、去重和取消，全量退出也覆盖尚未结束的临时操作。检查释义、原声、收录和测验资料保持，内存回执有界且活跃操作不被淘汰。

TC-05/20 的中文预习补充：不打开预习页也会对已有/新导入的缺失资料生成中文，任务页有聚合与分集进度；模型默认串行，按保存的并发上限取得请求许可，缓存复用，离开页面继续。打开或滚动预习只读库，不触发单词模型请求；快速切词、切换语境和纠正原句不会显示旧译文。取消和模型错误保留已完成结果，继续仅处理缺失；原生重开恢复，手动暂停不擅自恢复。自动准备不增加词条/学习记录，中文带入草稿后可修改，手动离线仍允许本机模型。

本次并发配置采用最小正常路径：在设置中保存 2，正常读取已保存值；对两个不同目标/语境发出同时在途请求，均返回有效中文并入库，聚合进度为 2/2、仍只保留一个任务。前端只确认新增控件及一次保存流程，必要类型/构建检查通过即交付。既有计划中的额外异常、取消竞态、兼容矩阵、负载或模型性能测试，不因本次新增功能自动执行，须先取得用户明确授权。

批量优化的最小正常路径：一处合成对白包含八个目标，其中一个已有解释，其余七个共用一次 HTTP 请求。通过配置的真实本机模型返回逐词有效中文和同一译文，七项分别入库，已缓存资料保持，进度为 7/7 且仅一个聚合任务。只验证这一正常样本，不追加故障、压力或时长对比测试；请求减少比例不等同于已测运行耗时提升。

可配置批大小采用一个正常流程：保存 3 并重开应用读回 3，同句七个缺失词的首个请求含三项；运行中保存 4，剩余四项合并为下一个请求，七项入库、进度 7/7、仍为同一聚合任务。前端完成新增控件的类型检查；不额外执行模型吞吐、故障或范围矩阵。

TC-05/20/39 的数量口径补充：多集、同词多句及部分缓存场景中，任务的候选数等于涉及来源的资料选择器候选数之和；进度明确标为本次待补充词语语境，不能与单词数混称。旧终态与历史记录保持该单位及原始处理量；分集候选/语境明细、未完成原因默认折叠。读取候选统计失败不显示错误零值，普通导入任务不使用语境单位，小窗口进度不横向溢出。缩略词只有英文展开式时继续拒绝保存，中文提示的真实模型样本单独记录，不推断所有失败项均已修复。

TC-05/20/39 的模型恢复补充：模拟一次 503 后成功，以及连接中断后恢复，任务等待后自动继续，taskId、工作总量与已保存缓存保持，重试尝试不新增历史或累计进度。等待中人工立即重试复用原任务；取消迅速结束并保存暂停，退出不继续发送请求。无效输出补试一次，可恢复或标记未完成后继续下一项；HTTP 400 等不可自动恢复错误保留原因和手动继续路径。界面区分等待、部分未完成和历史失败，重试按钮请求中禁用，小窗口完整可访问。真实模型正常可用与故障注入恢复分别记录，不以健康检查或纯界面模拟证明完整恢复。

TC-05 的资料定位补充：数百份来源按剧名/季/集缩小选项，编号 2 排在 10 前；搜索剧名、集名、S01E24、多关键词、无结果及清除。同集音轨/字幕和同名版本全部可选，未识别保留完整标题，同名年份不误合并。新导入刷新不改变有效选择，快速跨集切换的晚响应不混入当前候选、例句或音频，小窗口无横向溢出。

TC-05/20 与 NFR-02 的持久化补充：生成中文词义、译文和说明后检查 SQLite，关闭程序并清空测试浏览器缓存，更换为不可连接的模型地址，重开仍显示已保存内容；缺失记录可单独重试，模型失败不阻止其他数据库记录显示。旧缓存迁入后保留于数据库，重复迁移不覆盖资料；超过 500 条不淘汰数据库记录。升级 schema 5 时保留人工词义、例句、原声、测验与同步状态；无效模型输出不保存，数据库失败不可显示为保存成功。

## 5 执行记录与缺陷处理

每次执行记录测试编号、需求编号、提交或构建、环境、资源与策略版本、输入、操作、预期、实际、状态和证据位置。音频场景需要实际播放核对，仅 HTTP 成功、文件存在或声音已枚举不足以通过。

状态采用未执行、通过、失败、受阻、不适用及“用户接受结束”。“用户接受结束”用于用户明确同意未实测项先结案、不阻塞后续开发；须保留原执行证据与未实测事实，不等同实际测试通过。受阻说明缺少的条件；不适用说明已确认的范围依据。缺陷关联失败场景与对应模块，修复后重测受影响场景，只有新的失败或未决问题才扩大测试范围。

模拟站点、模拟模型和规则测试的证据分别记录，与真实服务及桌面操作的结果区分。当前结果见 [首轮原型验证记录](prototype-results.md)，后续按实际验证增量更新，未覆盖场景不能据局部证据标为通过。
