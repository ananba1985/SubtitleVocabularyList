本包包含 FR-25 的原生播放器输出修正：删除应用自建 OpenGL 绘制循环，改由完整 mpv 的原生 D3D11 输出、硬件解码及渲染线程负责基础播放。修复前后的代码依据和同源视频后台静音正常证据见[播放记录第 8 节](../testing/playback-results.md#8-0164-原生播放器输出修正)。本次仅打包，不追加实际窗口、音频、性能或画质比较测试。

2026-10-22 从干净源码 `61c63b66684c9b21d6cdc1ffd0aa732cc7d58311` 执行根目录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\生成安装包.ps1 -SkipToolBuild -NoPause
```

复用既有 OCR／Whisper／FFmpeg，仍准备固定 libmpv 和双底库，检查播放器归档／DLL 摘要、x64 架构及加载依赖，收集 341 项锁定依赖的许可。前端生产构建与接口契约检查通过，Rust release 编译耗时 9 分 46 秒，NSIS、独立目录、源码材料与摘要生成完成，脚本退出 **0**。未使用导入和 Vite 分块体积提示保留，没有中断构建。
