## 3 用户安装与操作验证

1. 先从托盘退出旧版，运行安装器，继续选择 `D:\SubtitleVocabularyList`，沿用该目录的 Data。
2. 点击“打开剧集”、列表中的视频或“继续上次列表”，确认直接开始播放，无需再点播放。
3. 普通窗口点击“■ 停止播放”；全屏可移动鼠标后点击原生浮动控制条右侧“■”，视频右键菜单也有“停止播放”。确认当前视频关闭、声音停止、退出全屏，列表和进度保留。

本次只生成并核对交付文件，没有重新执行实际窗口、声音、拖放或性能验收，不把此前内部鼠标事件验证当作真人桌面点击。
